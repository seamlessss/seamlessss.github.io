    L8：表征学习

    01 什么是表征学习？

    表征是对数据==含义==的编码，是对原始数据的映射。

    • 核心目的：让计算机能够理解数据的本质。一个优秀的表征空间，能够做到“语义相似 = 几何接近”（例如：在表征空间中，“猫”和“狗”的距离很近，而“猫”和“汽车”的距离很远）。

    1. 传统表征提取模式：特征工程

    在深度学习爆发前，表征提取依赖于领域专家人工手动设计规则，从原始数据里 “提炼” 出特征（也就是表征）。

    • 文本领域：
    • 词袋模型 (Bag of Words, BoW)：统计每个词在句中出现的次数。
      • 缺点：完全丢失语序和上下文关联（“狗咬人”和“人咬狗”向量完全一致）。
    • TF-IDF：在词袋的基础上，再手动设计规则：词重要性 = 词频 (TF) $\times$ 逆文档频率 (IDF，词在整个语料里的稀有度)。突出在当前句高频、但在全局罕见的“关键词”。
    • 图像领域：
    • SIFT (尺度不变特征变换)：手动设计了一套规则：先找图像里的 “关键点”（比如角点、边缘点），再计算关键点周围的梯度方向，生成一个对缩放、旋转不敏感的描述子（向量），作为图像的局部特征。
    • HOG (方向梯度直方图)：划分网格统计梯度分布，常用于提取行人轮廓。
    • 特征工程的缺陷：
    • 需要人工设计特征模式，需要领域经验，设计成本高
    • 只能表达局部语义，难以捕捉复杂语义，难以建模非线性结构
    • 泛化能力弱，需要对任务针对性的设计特征

    2. 现代范式：表征学习

    ==数据驱动==代替人工设计，用模型来学习表征

    为什么需要表征学习？

    • 降低数据维度，捕捉数据语义，提升泛化能力

    根据监督信号的来源，分为两类：

    • 有监督表征学习：利用人工标注的标签（如：图类别，目标框）进行端到端训练。
    • 依赖下游任务标注
    • 局限：标注成本极高；模型容易对特定任务过拟合，学到的表征迁移到新任务时效果不佳。
    • 无监督/自监督表征学习：从数据本身的结构与分布中，自动构造监督信号（伪标签）。
    • 依赖数据自身特性
    • 优势：数据零成本，可利用海量无标注数据；学到的表征更加通用，泛化性和迁移能力极强。

    3. 评估无监督表征的好坏

    1. 线性探测 (Linear Probing)：将训练好的 Backbone 冻结，只在其之上接一层简单的线性分类器，使用少量标注数据训练。分类准确率越高，说明 Backbone 提取的特征线性可分性越强，表征越好。
    2. 可视化观察聚类效果：使用 PCA 或 t-SNE 算法将高维特征降至 2D/3D，观察同类样本是否自然聚拢，不同类样本是否分离。

    02 Pretext 任务

    核心思想：摒弃人工标注，以数据自身属性为“伪标签”，通过人为设计一个代理小任务（Pretext Task），让模型在解决这个任务的过程中，被迫习得数据的深层语义。

    1. 经典的图像代理任务

    • ==旋转预测 (Rotation Prediction)==：将图像随机旋转 $0^\circ, 90^\circ, 180^\circ, 270^\circ$，让模型预测旋转角度（4 分类）。

    • 学到了什么：模型必须识别物体的主体轮廓、物体朝向和重力方向（树是竖直的，天在上面），从而理解空间语义，而不是只靠边缘、颜色这些低级特征。

    • ==相对位置预测 (Context Prediction)==：从同一张图片里随机采样两个局部区域（patch），让模型预测第二个 patch 相对第一个 patch 的位置（8 个方向，是一个 8 分类任务）。

    • 学到了什么：理解物体的整体结构和部件间的空间关系（如猫耳朵一定在猫眼睛上方）。

    • ==拼图游戏 (Jigsaw Puzzle)==：把一张图片分成 9 个小方块，打乱它们的顺序，让模型预测正确的排列方式（从 9! 种排列中选 100 种做分类）。

    • 学到了什么：局部到全局的推理能力，物体结构建模能力，上下文一致性。

    • ==着色 (Colorization)==：把彩色图片转成灰度图，让模型预测每个像素的颜色（在 Lab 颜色空间中恢复 a、b 通道）。

    • 颜色和语义强相关：天空是蓝的、草是绿的、皮肤有固定色调。模型要正确上色，必须理解物体的类别、场景上下文和纹理材质，而不是瞎猜颜色。

    • 学到的什么：物体语义理解、场景上下文建模。

    2. 局限性

    1. 泛化性有限：模型可能只是学会了解决 “猜位置 / 猜角度 / 猜颜色” 这道题，而不是学到了通用的视觉特征，迁移到下游任务时效果打折扣。
    2. 容易走 “学习捷径”：模型可能靠边缘连续性、相机伪影这些低级特征取巧，而不是真正理解物体的高层语义（比如着色任务里，模型可能靠颜色分布的统计规律上色，而不是识别出 “这是草，所以是绿的”）。

    03 对比学习

    既然代理任务容易被钻空子，研究者回归了分类的本质：让模型学会“区分谁是谁”。在特征空间中，==拉近同类事物，推远不同事物==。

    • 监督对比学习：需要人工标注哪些属于同类事物，哪些属于不同类事物 -> 成本太高
    • 自监督对比学习：通过数据变换自动构建正负样本对用于模型训练 -> free lunch!

    1. SimCLR

    Simple Framework for Contrastive Learning

    SimCLR 证明了只要有足够强的策略，纯自监督模型的特征提取能力可以匹敌有监督模型。

    • SimCLR 框架：对每张图施加两种不同的数据增强，形成一对互为“正样本”的分身。
    • 模型的目标就是识别出这些分身属于同一母体，并同时排斥 batch 内的所有其他图片。

    数据增强 (Data Augmentation)

    在保留数据原本含义的前提下，通过旋转、翻转等方式对现有数据进行变换，从而创造出更多新样本。

    • 关键发现：
    • 数据增强组合对自监督学习质量起决定性作用
    • 单纯的随机裁剪往往效果不佳（模型作弊），必须与“颜色抖动”结合使用

    基础编码器 (Base Encoder)

    • 通常采用经典的卷积神经网络（如 ResNet），作为模型的“主干”负责将原始图像转化为高维特征向量，旨在捕捉图像中核心的语义内容

    ==投影头 (Projector)==

    • 结构：一个两层的 MLP（全连接 + ReLU + 全连接），输出 $z$。
    • 作用：去冗余缓冲层。专门负责吸收和过滤掉那些对对比任务有用、但对通用识别没用的冗余信息（颜色、位置），保护前面的编码器能学到更纯净、更本质的语义特征。
    • 原始特征 $h$ 中包含了很多有用的通用信息（如颜色、朝向），但对比学习的任务会强迫模型扔掉这些信息（因为同一个物体的两个增强视图颜色不同，模型为了让它们相似，会学着忽略颜色）。Projector 充当了“替罪羊”，过滤掉对对比任务有用但对下游任务无用的信息。下游迁移时，扔掉 Projector，只保留 Encoder 提取的特征 $h$。

    ==对比损失 (NT-Xent 损失)==

    • 最大化同一图像不同增强视图（正样本对）之间的相似度，同时最小化不同图像（负样本对）之间的相似度。

    $$l(i,j) = -\log \frac{\exp(s_{i,j} / \tau)}{\sum_{k=1}^{2N} \mathbb{1}{[k \neq i]} \exp(s{i,k} / \tau)}$$

    • 计算正样本对$$i,j$$之间的相似度$$s_{i,j}$$。
    • 同时计算当前样本与所有负样本的相似度之和。
    • 目标是让正样本的相似度指数尽可能大（分子），让负样本的相似度指数尽可能小（分母）。

    Batch 机制：它利用整个 Batch 内的样本作为负样本库，极大丰富了负样本数量，是保证效果的关键之一。

    下游任务应用

    • 经过 SimCLR 训练之后的模型可以用于迁移学习。为此，使用来自基础编码器的表示，这些表示可以很好地应用于像 ImageNet 分类这样的下游任务。

    特征提取：利用海量无标签数据训练好 SimCLR 后，抛弃投影头，只保留基础编码器（Backbone）。

    微调（Finetuning）：在少量标注数据（如图中的 ImageNet）上，对编码器进行少量参数的微调。

    只要有足够大的 Batch、足够强的数据增强和一个简单的投影头，纯粹靠 “让模型分辨同与不同”，就能训练出特征能力极强的视觉模型，无需人工标注。

    • SimCLR 的痛点：严重依赖极大的 Batch Size（如 4096）来提供足够的负样本，对算力要求极高。

    2. MoCo——动量更新Encoder

    Momentum Contrast

    解决 SimCLR 依赖 “大 Batch” 的痛点

    对比学习的效果，很大程度上取决于负样本的数量和质量：

    • 负样本越多，模型越能学到 “区分不同样本” 的能力；
    • SimCLR 靠扩大 Batch Size 来增加负样本，但这对算力要求极高，普通设备很难跑。

    需要更多负样本的另一种解决方案：引入样本队列记住负样本的特征；使用非对称更新的方式，让其中一个Encoder以动量的形式进行更新。

    注：SimCLR发表更晚消融更全面，发现算力充足不如直接开大Batch

    • 样本队列 (Queue)：引入一个固定大小的先进先出（FIFO）队列，存储之前批次的旧特征作为负样本（如 $K=65536$）。这样即便当前 Batch 只有 256，也能拥有几万个负样本。

    • 动量编码器 (Momentum Encoder)：

    • 问题：如果负样本特征是用很久以前的参数算出来的，那跟现在参数算出来的 Query 就没有可比性（一致性被破坏）。

    • 解法：网络被分为 Query Encoder (参数 $\theta_q$) 和 Key Encoder (参数 $\theta_k$)。

      Query Encoder：实时更新参数$\theta_q$，用来处理当前输入$x^{query}$，得到query特征q；

      Key Encoder： $\theta_k$ 不进行梯度反向传播，而是以指数移动平均 (EMA) 极其缓慢地跟随 $\theta_q$ 更新：$$\theta_k \leftarrow m\theta_k + (1-m)\theta_q$$

      其中动量系数 $m$ 通常高达 0.999。这样保证了队列中所有的历史特征都是在非常相近的模型参数下生成的，保持了高度的一致性。

    样本队列（Queue）：把历史负样本存起来

    动量更新编码器：保证负样本的稳定性

    04 单词的表征学习

    1. 传统 One-hot

    • 火车 = [0,0,0,1,0]，高铁 = [0,0,0,0,1]。
    • 痛点：任意两个词的向量点积均为 0（完全正交），无法体现出“火车”和“高铁”极其相似的语义，且面临极其严重的维度灾难（词表多大，维度就多大）。

    2. Word2Vec

    • 分布式假设：一个词的含义由经常出现在它附近的词（上下文）决定。

    Word2Vec 算法

    统计语言模型——最大化文本语料的概率

    • 前提：有一个大的语料库
    • 词表Vocabulary中每个单词由一个向量表示
    • 对于文本中的每个位置t，有一个中心词c和上下文o
    • 可以通过c和o的向量相似度，来计算当中心词是c时上下文是o的概率（或当上下文是o时中心词是c的概率）
    • 通过调整单词的向量，使得语料库中上述概率最大化

    最大化 “中心词 - 上下文词” 的共现概率

    通过浅层神经网络将词映射到低维稠密向量空间。

    两种变体：

    1. Skip-gram：用中心词预测上下文。对低频词友好，特征更细腻，被更广泛应用。
    2. 逻辑：给定中心词 w(t)，让模型预测它周围的上下文词 w(t-2), w(t-1), w(t+1), w(t+2)。

    3. 优势：对低频词更友好，每个词都能单独参与预测，不容易被高频词淹没，也是图里重点介绍的模式。

    4. CBOW (Continuous Bag-of-Words)：用上下文预测中心词。对高频词友好。

    5. 逻辑：把中心词周围的上下文词 w(t-2), w(t-1), w(t+1), w(t+2) 加起来取平均，再让模型预测中心词 w(t)。
    6. 特点：高频词的训练更稳定，但低频词容易被高频词 “平均” 掉，效果不如 Skip-gram 稳定。

    Skip-gram 的训练流程

    以句子 problems turning into banking crises as 为例，窗口大小设为 2（中心词前后各 2 个词）：

    1. 定义中心词和上下文词

    2. 当中心词是 into（位置 t），上下文词就是前后 2 个词：problems, turning, banking, crises，模型的目标是最大化 P(problems|into)、P(turning|into)、P(banking|into)、P(crises|into)。

    3. 当中心词是 banking（位置 t），上下文词就是 turning, into, crises, as，模型的目标是最大化 P(turning|banking)、P(into|banking)、P(crises|banking)、P(as|banking)。

    4. 窗口滑动

    5. 在整个语料库中，窗口会不断滑动，每个词轮流当中心词，周围的词当上下文词，生成大量 “中心词 - 上下文词” 对，用来训练模型。

    6. 计算过程

    7. 目标：最大化文本语料中“中心词-上下文词”的共现概率（极大似然估计）。

    8. 损失函数 (负对数似然)：

      ==$$J(\theta) = -\frac{1}{T} \sum_{t=1}^{T} \sum_{-m \le j \le m, j \neq 0} \log P(w_{t+j} \mid w_t ; \theta)$$==

    9. 原始 Softmax 计算：

      ==$$P(o \mid c) = \frac{\exp(u_o^\top v_c)}{\sum_{w \in V} \exp(u_w^\top v_c)}$$==

      (每个词维护两个向量：作中心词时的 $v_c$，作上下文时的 $u_o$)。

    两大优化

    原始 Softmax 的分母需要遍历整个巨大的词表 $V$（例如 10 万字），每次更新计算量无法承受。

    1. 负采样 (Negative Sampling)：

    • 将一个极其复杂的多分类问题，简化为多个独立的二分类问题。
    • 对于每个中心词 $c$，除了它真实的上下文 $o$（正样本），随机从词表中抽取 $K$ 个不想干的词作为负样本。

    • 目标变为：最大化正样本对的 Sigmoid 概率，最小化负样本对的概率。无需再计算全词表！

    • 层次 Softmax：

    • 将所有词构建成一棵 Huffman 二叉树（高频词靠近根节点）。将求概率问题转化为从根节点走到叶子节点的一系列二分类问题。计算复杂度从 $\mathcal{O}(|V|)$ 直接降至 $\mathcal{O}(\log |V|)$。

    3. 从局部上下文预测到全局统计

    语义关系是否可以直接从“全局统计结构”中恢复？

    现象：单词共现矩阵（co-occurrence matrix）蕴含了相似度语义

    GloVe算法的思想与目标函数

    Word2Vec 只利用了局部的上下文滑动窗口。GloVe 则直接利用全局的词共现矩阵 (Co-occurrence Matrix)。

    • 核心目标：强迫两个词向量的内积，等于它们在整个语料库中共同出现次数的对数。
    • 经典性质：表征的线性平移结构：由于基于对数共现概率，GloVe 学到的空间具有惊人的线性代数规律：$v_{woman} - v_{man} \approx v_{queen} - v_{king}$。

    05 文本数据的自监督学习

    1. Transformer——可扩展序列建模基座

    • RNN 必须从左到右串行计算（无法并行），且存在长程记忆遗忘问题。
    • Transformer 的自注意力机制 (Self-Attention)：
    • 允许序列中所有位置完全并行计算。
    • 任意两个词的距离均为 1（矩阵点积直达），彻底解决长程依赖。
    • 开启 Scaling Law：其并行特性使得在成千上万张 GPU 上训练超大参数模型成为可能。
    • Attention Is All You Need：不再需要复杂的循环神神经网络来提取表征。

    2. BERT

    Bidirectional Encoder Representations from Transformers，旨在通过自注意力使每一层都同时编码两侧上下文，实现更深层的双向理解

    • 去噪自编码：随机遮挡输入序列中 15% 的 Token，迫使模型利用左右双向的所有上下文来推理预测被遮挡的词（完形填空）。

    为了缓解预训练有 Mask 但微调阶段无 Mask 带来的不匹配，这 15% 的词中 80% 替换为 [MASK]，10% 随机替换为其他词，10% 保持原样

    • 双向掩码预测：每个被遮挡位置基于双向上下文输出词表概率分布

    • 在Transformer Encoder输出层，被遮挡位置对应的隐藏向量经简单分类头映射到词表空间，通过softmax分布预测原始token

      • 单向生成 → 双向去噪，为深度语义理解表征奠定基础

    BERT优势

    BERT通过双向去噪自编码预训练，在多项语言理解基准上显著超越此前的静态词向量与单向模型。

    通过为不同理解任务设计简单的输出层（如分类头或起止位置预测），BERT表征可直接支持情感分析、语义推理、问答抽取与实体识别等任务

    BERT局限

    • 训练规模保守，模型潜力尚未激发——Scaling Law
    • 引入的句级NSP (Next Sentence Prediction)辅助任务以及输入格式可能分散核心掩码——消融实验探究

    3. RoBERTa

    RoBERTa (Robustly optimized BERT approach) 在保持BERT架构完全不变的前提下，改变了训练规模：

    • 训练数据：16GB → 160GB
    • 步数：100K → 500K

    Scaling Law：架构不变的情况下，仅通过扩大数据规模、增加训练步数，明显性能提升。说明训练充分性比架构创新更能决定预训练模型上限。

    消融探究

    RoBERTa 移除NSP辅助任务，改变输入格式，进行了消融实验探究

    聚焦学习目标：预训练任务的设计应聚焦于核心表征学习目标，冗余的辅助任务不仅非必需，还可能干扰模型对深层语义结构的捕捉

    4. NTP回归——从理解到生成

    • BERT双向去噪——理解路线
    • NTP (Next Token Prediction)单向预测下一个token——生成路线

    NTP将序列建模为条件概率的连乘积，模型只能依赖左侧已生成内容来推断后续token，这种单向约束使其在生成流畅文本上具有先天优势

    NTP确立了自回归生成的训练范式，为GPT系列将技术路线从理解转变为生成奠定了目标函数基础

    5. GPT 系列

    • 目标转移：NTP (Next Token Prediction)： 不再做完形填空，而是单向自回归：给定前文，预测下一个 Token。

    • NTP 必须根据已知推断未知，这在本质上是一种强迫模型学习世界知识与推理逻辑的终极任务。它天然适合“生成式”应用。

    • 规模化涌现 (GPT-1 $\to$ GPT-3)： 坚持 Decoder-only 架构。GPT-3 以 1750 亿（175B）参数宣告大模型时代降临，展现出了强大的 上下文学习 和 zero-shot 能力。模型不再需要针对下游任务微调权重，只需给正确的 Prompt（提示词）即可工作。

    ChatGPT

    在GPT-3.5基础上引入==RLHF (Reinforcement Learning from Human Feedback)==，将模型输出与人类偏好对齐

    ChatGPT证明，在规模化预训练之后，对齐技术是激发生成模型实用价值的一个里程碑，为后续大模型产品化确立了预训练+对齐的标准路径

    6. Chinchilla

    动机

    基于Scaling Law，GPT-3后大模型普遍进行盲目扩参。性能提升唯一解法？

    • Chinchilla以与Gopher相同的计算预算、仅1/4的参数和4.7倍的数据，在广泛下游任务上全面超越Gopher、GPT-3、Jurassic-1及MT-NLG 530B
    • 结论：在相同计算预算下，主流大模型严重训练不足。缩小模型规模并等比例增加数据量，可获得更优的下游性能

    最优配比

    • Chinchilla通过对400余个模型（70M~16B参数）的训练曲线进行三种独立拟合，发现计算最优条件下模型规模与训练token数应近似等比例增长。推翻了此前结论“扩参远快于扩数据”
    • 模型规模与数据规模应随计算预算近似等比例扩展，约==20:1的token-参数比==成为计算最优训练的核心约束

    启示

    • Chinchilla表明，在固定计算预算下追求更大模型导致严重欠训练
    • 预训练的竞争指标应该从参数量转变为单位计算量的性能效率

    工程优势与伦理挑战

    Chinchilla不仅以更小模型获得更强性能，还显著降低了推理与微调的计算开销

    工程优势

    • 更优的模型并不一定需要更大的部署开销

    伦理挑战

    • 更大规模的数据将不可避免地包含有毒信息、社会偏见与私人信息。随着训练数据量级不断提高，数据集的质量控制、训练-测试重叠检测以及伦理审查变得至关重要

    06 图像与文本自监督学习的区别

    文本 NLP 的自监督（如 BERT）非常成功，但能否直接平移到视觉 CV 领域？

    1. 文本与图像的差异

    • 文本：离散符号。一个词（Token）含有高度浓缩的密集语义（Information-dense）。
    • 图像：连续信号。单个像素没有任何意义（Information-sparse），图像存在极大的空间冗余（相邻像素基本一样）。

    2. 图像掩码重建（Masked Image Modeling）

    核心思想：基于掩码的重建与理解 -> “通过残缺理解整体”

    通过遮挡图像75%的区域，迫使模型利用仅存的可见部分去重建全局内容，从而跳出局部纹理的局限，真正习得物体结构与语义关联。

    MAE

    计算聚焦策略：利用 75% 的高比例遮挡，让 Encoder 仅处理 25% 的可见图块，将计算资源集中在对核心语义的理解上，避免算力浪费

    非对称高效架构：重型 Encoder 学习强表征，轻型 Decoder 仅负责像素重建，解耦了学习与重建，将训练速度提升了 3-5 倍。

    说明了：高比例 Mask 不仅能够学习到更强的表征，还能提高效率！

    3. 图像序列预测（Image Sequence Prediction）

    iGPT：将图像展平为像素序列，类比文本生成逻辑，采用 Transformer Decoder 架构，通过自回归方式依据前序像素预测下一像素，实现图像序列的生成式建模。

    • 问题：计算量极大（序列太长），且像素级的自回归预测在视觉上不如掩码重建有效！

    SimMIM

    直接对图像块进行随机掩码并通过轻量预测头回归原始像素值。这种无需离散化或复杂结构的方案，不仅大幅降低了计算成本，还能适配 ViT、Swin 等多种骨干网络。

    自监督表征学习总结

    广泛应用

    自监督学习的核心就在于表征学习，即不依赖人工标注，而是通过从数据内部挖掘结构来自动生成监督信号，从而训练模型提取出能抓住数据本质的通用特征表示。
