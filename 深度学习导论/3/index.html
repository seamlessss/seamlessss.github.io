    L4：神经网络基础（一）

    01 回望感知机

    感知机(Perceptron)是二分类的线性分类模型。其核心思想是通过==错误驱动 (Error-Driven) 的梯度下降==迭代更新参数，最终找到一个能够将训练数据完全正确分类的超平面：$$w^{\top}x + b = 0$$

    1. 感知机算法流程

    • 初始化：$w = 0, b = 0$（或随机小值）。

    • 遍历训练集：寻找误分类样本 $(x_i, y_i)$。误分类的数学条件为：$$y_i(w^{\top}x_i + b) \le 0$$

    $$y_i$$是真实标签 ±1，误分类时模型输出与真实标签符号相反

    • 更新参数：一旦发现误分类点，立刻使用该样本更新参数：

    ​ $$w \leftarrow w + \eta y_i x_i$$

    ​ $$b \leftarrow b + \eta y_i$$

    其中 $\eta$ 为步长（学习率）。无论 $y_i$ 是 $+1$ 还是 $-1$，该更新方向都能保证 $y_i(w^{\top}x_i + b)$ 的值增大，即使模型向“纠错”的方向移动。

    2. 数学本质

    令 $M$ 表示算法当前错分的样本集合，感知机本质上是在近似求解以下最小化问题：

    $$\min_{w,b} \sum_{i \in M} -y_i(w^{\top}x_i + b)$$

    它实际上是用一个分段线性的可导函数，去近似不可导的 0-1 损失函数$$l_{0/1}(x,y) = \mathbb{I}(y(w^{\top}x + b) \le 0)$$

    3. 理论保证与局限性

    • Novikoff 定理：若训练数据集是线性可分的，则感知机算法一定能在有限步内收敛，得到一个能完全正确分类的超平面。

    • 线性不可分数据会导致算法无限循环，无法收敛。

      线性可分：存在超平面能将两类样本完全分开

      线性不可分：不存在这样的超平面

    • 若数据线性不可分（例如最简单的 异或问题 XOR），感知机算法将会陷入无限循环，无法收敛。这直接导致了历史上神经网络的第一次低谷。

    4. 其他线性模型

    • 假设空间 $${h(x) = \mathrm{sign}(w^\top x + b)}$$

    • ==逻辑回归==（最小化负对数似然，即最大化似然函数）$$\min_{w,b} \sum_{i=1}^m \log\big(1 + \exp(-y_i(w^\top x_i + b))\big)$$

      通过 Sigmoid 函数将线性输出映射为 [0,1] 概率，本质是对数几率回归。

    • ==支持向量机SVM==（间隔最大化+合页损失）$$\min_{w,b} \frac{|w|^2}{2} + C \sum_{i=1}^m \max\left{0, 1 - y_i(w^\top x_i + b)\right}$$

      间隔最大化。

      分类间隔（Margin）指的是：离超平面最近的样本点到超平面的距离。

      合页损失 $$\max\left{0, 1 - y_i(w^\top x_i + b)\right}$$

      合页损失只惩罚那些落在间隔内部或误分类的样本，对于远离边界的正确样本，它完全不在乎。

    例子

    Linear Regression

    Linear Regression with Activation Function

    z=1×1+0×(−2)+1×1+1=3

    若激活函数是阶跃函数（阈值为 2）：z>2 时输出 1，否则 0，所以最终 y=1。

    线性模型的局限性

    无法解决异或（XOR）问题

    • 在二维平面上，(0,0) 和 (1,1) 是一类（圆圈），(1,0) 和 (0,1) 是另一类（三角）。不存在任何一条直线能把这两类点完全分开 → 线性模型（感知机、逻辑回归、SVM 线性核）都做不到。
    • 线性模型的决策边界是直线（超平面）：$$ w^\top x + b = 0$$。异或问题的决策边界是折线/曲线，线性模型无法拟合这种非线性结构。

    02 多层感知机 (MLP)

    为了解决线性不可分问题，必须引入隐藏层 (Hidden Layer) 和 非线性激活函数，将多层结构叠起来，形成多层感知机（即最基础的全连接神经网络）。

    多层感知机(Multi-layer Perceptron, MLP)：由输入层，一个或多个隐藏层、输出层组成的前馈神经网络。

    1. 从单层到多层

    • 单层空间受限：单层网络只能划分出一条直线（或一个超平面），无法扭曲空间。

    • 多层空间扭曲：通过隐藏层将原始输入特征 $x$ 投影到一个新的特征空间，使其在新的空间中变得线性可分，再由输出层进行线性分类。

    • 示例：用于求解异或问题的2层感知机（输入层不计入层数）

    • 蓝色阴影区域是输出为 1 的区域。

    隐藏层的两个神经元实际上定义了两条直线（决策边界），输出层则对这两条直线的区域进行了 “与 / 或” 运算，从而拼接出了一个非线性的决策区域，完美解决了线性不可分问题。

    2. 前向传播的矩阵表达

    假设一个 3 层 MLP（输入层、1个隐藏层、输出层）：

    • 输入向量：$x \in \mathbb{R}^d$

    • 隐藏层：

    $$z^{(1)} = W^{(1)}x + b^{(1)}$$

    $$h^{(1)} = \sigma(z^{(1)})$$

    其中 $W^{(1)}$ 是权重矩阵，$b^{(1)}$ 是偏置向量，$\sigma(\cdot)$ 是非线性激活函数。

    • 输出层：

    $$z^{(2)} = W^{(2)}h^{(1)} + b^{(2)}$$

    $$\hat{y} = \text{g}(z^{(2)})$$

    （若为分类任务，$\text{g}(\cdot)$ 通常为 Softmax 或 Sigmoid ；若为回归任务，则直接输出）。

    3. 通用架构

    • 输入层(Input Layer)

    • 只是数据的搬运工，每个神经元对应数据的一个特征

    • 不需要计算，也没有激活函数，只是把数据 x 传递给下一层。

    • 隐藏层&输出层

    • 隐藏层 (Hidden Layers)：

      • 可以有多层，层数越深，模型拟合的特征越复杂（从边缘检测到抽象概念）。
      • 全连接（Full Connected）：上一层的每个神经元都与下一层的每个神经元相连。

      输出层 (Output Layer)：

      • 最终输出结果（分类概率、回归值等）。

    这是前向传播（Forward Propagation）的核心公式，将网络结构转化为矩阵运算。

    • 假设当前为第 $$\ell$$ 层，$$n_{\ell-1}$$ 为上一层的神经元数量（输入维度），$$n_{\ell}$$ 为当前层的神经元数量（输出维度）。

    • 每个神经元接收来自上一层的神经元的输入信号$$% 第 \ell 层神经元输入信号 \left[ x_1^{(\ell-1)}; \dots; x_{n_{\ell-1}}^{(\ell-1)} \right]$$

    • 每一个输入信号都有一个与之对应的权重$$% 第 \ell 层对应权重 \left[ w_1^{(\ell)}; \dots; w_{n_{\ell-1}}^{(\ell)} \right]$$

    • 每个神经元整合输入信号后得到 ==$$z_k^{(\ell)} = \sum_{j=1}^{n_{\ell-1}} w_{k,j}^{(\ell)} x_j^{(\ell-1)} + b^{(\ell)}$$==

    • 再经过激活函数 $$\sigma(z)$$ 后输出 $$x_k^{(\ell)} = \sigma!\left(z_k^{(\ell)}\right)$$

    03 激活函数 $$\sigma(z)$$

    激活函数 = 引入非线性，让模型能拟合复杂规律（用在==隐藏层==）

    问题：

    1. 函数不连续导致难以优化；

    阶跃函数在 z=0 处不可导。

    我们需要通过梯度下降来更新权重。如果函数是平直的或者突变的，梯度为 0 或无法计算，权重就无法更新，模型学不到东西。

    1. 二值化限制模型能力（假设空间变小）

    输出只有 {−1,1} 或 {0,1}。

    这会导致模型的表达能力（假设空间）非常有限。如果中间层输出太离散，就无法精细地刻画复杂的数据分布。

    常见激活函数

    激活函数 数学公式 特点与优势 主要缺陷
    Sigmoid $\sigma(z) = \frac{1}{1 + e^{-z}}$ 将输出压缩到 $(0,1)$，常用于概率输出。 当 z 很大/很小时，梯度消失；且输出不是0均值
    Tanh $\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$ 输出在 $(-1,1)$ 之间，是零均值的，收敛比 Sigmoid 快。 同样存在饱和区，在大激活值下会导致梯度消失。
    ReLU $\text{ReLU}(z) = \max(0, z)$ 计算极快（只需阈值化）；在正区间不饱和，极大缓解了梯度消失问题。 “死ReLU”问题：当输入为负时，梯度降为 0，该神经元可能永久坏死。
    Leaky ReLU $\text{L-ReLU}(z) = \max(\alpha z, z)$ 为负区间赋予一个小斜率 $\alpha$（如 0.01），保留微弱梯度。 解决了“死 ReLU 问题”，但超参数 $\alpha$ 需要人工微调。

    1. Sigmoid函数（==连续且平滑==）

    2. S型曲线，输出范围在(0,1)，z=0时输出0.5

    3. 优点：输出可以被认为是一种概率估计（逻辑回归本质就是用sigmoid做二分类），连续可导，适合梯度下降。

    4. 缺点：当 z 很大/很小时，梯度接近0（梯度消失），训练变慢；而且输出不是0均值，会影响后续层优化。

      什么情况下会走出之字形？当你的输入全是正数时（比如 sigmoid 输出 0~1）

      下一层计算：$$z=w_1x_1+w_2x_2+…$$所有 x ≥ 0

      那么梯度的符号会被固定死：要么全部往上,要么全部往下

      梯度不能 “精准指向目标”，只能斜着走、来回震荡。

      就像你要去东南方向，但你只能先往右走一段,再往下走一段,再往右,再往下。走出来就是之字形。

      为什么之字形慢？

      因为正常一步走到的地方， zigzag 要走 10~100 步。

      而且步长还不能太大，太大就飞过了。

      所以训练速度差一个数量级。

      为什么 0 均值能解决？

      因为输入有正有负：

      • 有的 x 正，有的 x 负

      梯度方向可以自由指向任意角度，直接冲向最小值。不用来回拐。

    5. Tanh函数

    6. S型曲线，输出范围在(-1,1)之间，z=0时输出0

    7. 优点：输出是0均值，比sigmoid更适合做隐藏层激活。

    8. 缺点：同样存在梯度消失的问题。

    9. ReLU函数连续但不可导（实践中非常有效）

    10. z>0时输出z，其他时候输出0

    11. 优点：计算极快，正区间梯度恒为1，缓解梯度消失；实践中效果最好，是目前 CNN/Transformer 的默认激活

    12. 缺点：z=0处不可导（工程上用次梯度解决）；存在“死ReLU”问题：部分神经元永远输出0（梯度为0，无法更新）

    13. Leaky ReLU函数

    14. z>0 时输出 z，z≤0 时输出很小的 αz

    15. 优点：解决了死 ReLU”问题：负区间也有微小梯度，神经元不会 “死亡”；保留了 ReLU 计算快、梯度稳定的优点

    04 数学表达

    • 输入层（0层）：$$% 输入层 x^{(0)} = \left[ x_1^{(0)}; \dots; x_{n_0}^{(0)} \right]$$$$x^{(0)} = \left[ x_1^{(0)}; \dots; x_{n_0}^{(0)} \right]$$

    • 隐藏层&输出层（第$$\ell$$层）：

    $$z^{(\ell)} = \left( \sum_{j=1}^{n_{\ell-1}} w_{1j}^{(\ell)} x_j^{(\ell-1)} + b_1^{(\ell)}, \dots, \sum_{j=1}^{n_{\ell-1}} w_{n_\ell j}^{(\ell)} x_j^{(\ell-1)} + b_{n_\ell}^{(\ell)}\right)$$$$% 第 \ell 层激活 x^{(\ell)} = \sigma^{(\ell)}!\left(z^{(\ell)}\right)$$

    $$x^{(\ell)} = \sigma^{(\ell)}!\left(z^{(\ell)}\right)$$

    • $$ w_{1j}^{(\ell)} $$表示第$$\ell$$层的第$$i$$个神经元赋予前一层的第$$j$$个神经元输入信号的权重
    • $$ b_1^{(\ell)}$$表示第$$\ell$$层的第$$i$$个神经元的偏置
    • $$% 第 \ell 层激活 x^{(\ell)} = \sigma^{(\ell)}!\left(.\right)$$表示第$$\ell$$层的激活函数

    变成矩阵形式：

    $$z^{(\ell)} = W^{(\ell)} x^{(\ell-1)} + b^{(\ell)}$$

    $$x^{(\ell)} = \sigma^{(\ell)}!\left(z^{(\ell)}\right)$$

    • $$ W^{(\ell)} $$: 权重矩阵，表示第$$\ell$$层的第$$i$$个神经元赋予前一层的第$$j$$个神经元输入信号的权重。形状为$$[n_{\ell} ,n_{\ell-1} ]$$(当前层神经元数*上一层神经元数)。$$W^{(\ell)} = \begin{bmatrix} w_{11} & \dots & w_{1n_{\ell-1}} \ \vdots & \vdots & \vdots \ w_{n_\ell 1} & \dots & w_{n_\ell n_{\ell-1}} \end{bmatrix}$$

    • $$b^{(\ell)}$$: 偏置向量，表示第$$\ell$$层的第$$i$$个神经元的偏置，形状为$$[n_{\ell} ]$$，为$$b^{(\ell)} = \begin{bmatrix} b_1^{(\ell)}; \dots; b_{n_\ell}^{(\ell)} \end{bmatrix}$$

      如果是另一个输入(0,0)：

    神经网络的每一步前向传播，本质就是做一次矩阵乘法，然后套一个激活函数。

    矩阵乘法：高度可并行化（Parallelism），适合用 GPU 加速

    深度 vs. 宽度

    • 1989年，George Cybenko证明了，当激活函数是sigmoid型函数时，只有单隐层的多层感知机就可以在任意精度下逼近定义在紧集上的任意连续函数。——通用近似定理

    • 回答了一个非常根本的问题：一个简单的神经网络结构，在理论上有没有能力表示足够复杂的函数？

    • 足够宽在理论上能保证能力：只要一个前馈神经网络拥有一个隐藏层且神经元数量足够多，激活函数采用连续的sigmoid函数（或其他满足条件的非线性函数），它就可以以任意精度逼近定义在紧集上的任何连续函数

    • 非线性激活函数的关键作用：只要加入一个非线性激活函数（如sigmoid、tanh、ReLU的某些变体），并在隐藏层给予足够的自由度，神经网络就不再受限于线性模型，而成为一种通用的函数逼近器

    • 激活函数的重要性：

    • 如果去掉激活函数，无论堆叠多少层感知机，整个网络的表达能力都等价于一层线性模型，和直接用 y=Wx+b 没有区别，深度学习就退化成了普通线性回归。

    • 假如没有激活函数，多层感知机（记总层数为$$L$$)等价于线性模型，即存在参数$$W,b$$使得$$x^{(L)} = W x^{(0)} + b$$

    • 隐藏层&输出层（第$$\ell$$层）：

      • 数学归纳法证明：多层线性等价于单层线性——任意 L 层纯线性网络，都可以合并成一个 W 和一个 b。
      • 当$$\ell=1$$时，上述结论显然成立；假设对于任意$$\ell\ge 2$$有上述结论，则$$x^{(\ell+1)} = W^{(\ell+1)} x^{(\ell)} + b^{(\ell+1)} = W^{(\ell+1)} W x^{(\ell)} + W^{(\ell+1)} b + b^{(\ell+1)}$$依然是一个线性模型

    论文表明：存在一类函数，可以用深度为3层（或更一般地，$$O(log d)$$甚至$$O(k^3)$$的神经网络精确表示，其中网络的总参数量是多项式级的，但如果限制网络深度为2层（或深度远小于某个与函数结构相关的参数$$k$$），那么为了逼近该函数，所需的神经元数量（即参数量）必须至少是指数级（相对于$$k$$或输入维度$$d$$）。

    • 证明了==深度==在神经网络表达能力中起着关键作用——深度可以指数级地减少表示某些函数所需的参数量。

    总结

    通用近似定理

    结论：单隐层网络（宽度足够大）可以以任意精度逼近紧集上的任意连续函数。

    性质：

    • 回答的是存在性（“能不能”）
    • 不关心达到该精度需要多少神经元
    • 对所有连续函数都成立

    Telgarsky(2016) 与 Elden&Shamir(2016)

    结论：存在某些函数，用深层网络（比如3层或$$O(k^3)$$层）可以高效表示（多项式级参数），但用浅层网络（如2层）表示时，所需的宽度必须是指数级（相对于某个复杂度参数）。

    性质：

    • 回答的是效率性（“好不好/省不省”）
    • 只针对某些特定的函数，不是所有函数
    • 对比的是不同深度下的参数复杂度

    足够宽的单隐层网络具有通用逼近能力，但深度可以在某些函数上指数级地节省参数

    多层感知机：梯度计算

    确定损失函数后，多层感知机的参数优化同样遵循经验风险最小化原则。因此一般会被转化为优化问题，再利用梯度信息进行迭代求解。

    经验风险最小化（伊多分类问题为例）

    • $$\arg\min_\theta \mathcal{L}(\theta, D) = \sum_{i=1}^m \sum_{c=1}^k -y_{i,c} \log \hat{y}_{i,c}$$

    • 其中$$\hat{y}_{i,c}$$由多层感知机的参数$$\theta$$以及数据特征$$x_i$$确定

    • 单参数场景

    • 多参数场景（等高线图）

    • 经验风险最小化 -> 最优化问题

    • ==梯度下降（GD）==：用全部训练数据计算梯度，准确但慢。

    • ==随机梯度下降（SGD）==：用单个样本计算梯度，快但噪声大。

    • ==小批量梯度下降 (Mini-batch SGD)==：用一小批样本计算梯度，兼顾速度和稳定性（最常用）。

    • $$\theta_{t+1} = \theta_t - \eta_t \nabla \mathcal{L}(\theta_t, D) $$ or $$\theta_{t+1} = \theta_t - \eta_t \widetilde{\nabla} \mathcal{L}(\theta_t, D)$$

    • 还有牛顿法、拟牛顿法等，利用二阶信息，收敛更快但计算更复杂。

    • 梯度下降会遇到的问题

    • 局部最小值(Local Minima)

      • 曲线里有很多小坑，梯度下降可能会卡在某个小坑里，找不到真正的全局最低点。

      → 但在深度学习中，局部最小值通常也足够好，或者通过动量、自适应学习率可以跳出.

    • 鞍点(Saddle Point)

      • 某个方向梯度为 0，另一个方向还能继续下降，梯度下降会在这里卡住。

      → 同样，动量等方法可以帮助冲过去。

    • 高原区(Plateau)

      • 曲线变得非常平缓，梯度接近 0，更新速度极慢。

      → 这时候需要调整学习率，或者用更高级的优化器（如 Adam）。

    标量函数梯度

    • 令$$f(\cdot): \mathbb{R}^d \mapsto \mathbb{R}$$表示一个可微函数（即输入是d维向量，输出是一个标量）。那么$$f(\cdot)$$在$$x \in \mathbb{R}^d$$处的梯度同是一个位于$$\mathbb{R}^d$$空间内的向量（每个分量是 f 对对应输入变量的偏导数在 x 处的取值）

    • 梯度：$$\nabla f(x) = \left[ \frac{\partial f}{\partial x_1}(x); \dots; \frac{\partial f}{\partial x_d}(x) \right]$$

    • Eg. $$f(x) = -\sum_{i=1}^d x_i \ln x_i$$，则$$\nabla f(x) = \left[ -(\ln x_1 + 1); \dots; -(\ln x_d + 1) \right]$$
    • 方向：梯度$$% 梯度定义 \nabla f(x)$$的方向是函数 f 在点 x 处上升最快的方向：如果沿着梯度方向移动，函数值增加得最快；反之，沿负梯度方向$$(-\nabla f(x))$$移动，函数值下降最快。
    • 大小：梯度的模$$||\nabla f(x)||$$表示在该方向上函数变化的变化率。如果从 x 触发，沿着梯度方向走一小步，函数值会增加$$||\nabla f(x)|| * 步长$$：模越大，该点附近函数越陡峭；模越小，函数在该点附近越平坦。

    向量值函数梯度

    • 令$$% 函数定义 f(\cdot) = [f_1(\cdot), \dots, f_m(\cdot)]: \mathbb{R}^d \mapsto \mathbb{R}^m$$，其中每个$$f_i(\cdot)$$都是可微函数。那么$$% 函数定义 f(\cdot)$$在$$x \in \mathbb{R}^d $$处的梯度是一个大小为$$\mathbb{R}^{m ×d}$$的矩阵，具体定义如下：$$\nabla f(x) = \begin{bmatrix} \frac{\partial f_1}{\partial x_1}(x) & \dots & \frac{\partial f_1}{\partial x_d}(x) \ \vdots & \ddots & \vdots \ \frac{\partial f_m}{\partial x_1}(x) & \dots & \frac{\partial f_m}{\partial x_d}(x) \end{bmatrix}$$，也成为雅可比（Jacobian）矩阵

    海森矩阵（二阶导数）

    • 令$$ f(\cdot) : \mathbb{R}^d \mapsto \mathbb{R}$$表示一个二次可微函数。那么$$% 函数定义 f(\cdot) $$在$$x \in \mathbb{R}^d $$处的海森是一个大小为$$\mathbb{R}^{d ×d}$$的矩阵，具体定义如下：$$ \nabla^2 f(x) = \left[ \frac{\partial^2 f}{\partial x_i, x_j}(x) \right]_{1 \leq i,j \leq d}$$

    • 样例：$$ f(x) = -\sum_{i=1}^d x_i \ln x_i$$，

    eg.

    变量之间完全独立

    • $$ \nabla^2 f(x) = \mathrm{diag}\left( -\frac{1}{x_1}, \dots, -\frac{1}{x_d} \right)$$
    1. 判断极值点（二阶充分条件）

    对于优化问题，梯度为零的点（驻点）可能是局部极小值、局部极大值或鞍点。梯度只能告诉我们“这里是平的”，但无法区分是谷底（极小值）、山顶（极大值）还是马鞍面（鞍点）。

    海森矩阵H的正定性可以给出判断：

    如果H正定（所有特征值>0）：该点是局部极小值。

    如果H负定（所有特征值<0）：该点是局部极大值。

    如果H不定（特征值有正有负）：该点是鞍点。

    这在分析损失曲面的形状、理解神经网络的陷入鞍点等问题中非常关键。

    1. 影响梯度下降的收敛速度

    梯度下降的收敛速度取决于损失函数在最优解附近的曲率（即海森矩阵的条件数）。

    • 条件数=最大特征值/最小特征值，条件数越大，收敛越慢。

    • 如果海森矩阵的条件数很大（即曲面在某个方向很陡，在另一个方向很平坦），梯度下降会表现为“锯齿状”震荡，收敛很慢。
    • 海森矩阵的规模是参数数量的平方，对于深度网络（数百万甚至数十亿参数）完全不可存储和求逆。因此，实践中几乎从不直接使用海森矩阵，而是用其近似（如 Adam 的动量）或避免使用二阶信息。

    06 反向传播

    复合函数的链式法则

    $$ h(x) = f(g(x))$$

    • 梯度：$$h'(x) = f'(g(x)) g'(x) \quad \frac{\partial h}{\partial x} = \frac{\partial f}{\partial g} \cdot \frac{\partial g}{\partial x}$$
    • 海森：$$h''(x) = f''(g(x)) \left(g'(x)\right)^2 + f'(g(x)) g''(x)$$
    • Eg. $$ z = (x+y)^2 \quad\Rightarrow\quad z = t^2,\ t = x+y \quad\Rightarrow\quad \frac{\partial z}{\partial x} = \frac{\partial z}{\partial t} \frac{\partial t}{\partial x} = 2t \cdot 1 = 2(x+y)$$
    • 链式法则是神经网络基于梯度反向传播进行训练的核心
    • 损失函数对参数的梯度可以分解为从输出到输入的多个局部梯度的乘积，每个局部梯度容易计算。

    计算图

    • 计算图是由节点和边构成的有向图，其中节点表示变量或运算，边表示数据依赖关系，整个图描述了一个复杂函数由若干基本运算组合而成的过程

    • 多层感知机（和其它更复杂的深度模型）主要涉及有向无环图(Directed Acyclic Graph, DAG)，并假设各个节点可微

    在神经网络中，数据前向流动，误差反向流动。

    • 前向传播：输入 $x \rightarrow$ 经权重$W$乘加得到 $z \rightarrow$ 激活函数得到 $h \rightarrow$ 计算出损失 $L$。

    • 反向传播：为了更新权重 $W$，我们需要求 $\frac{\partial L}{\partial W}$。根据链式法则：

    $$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial L_{output}} \cdot \frac{\partial L_{output}}{\partial h} \cdot \frac{\partial h}{\partial z} \cdot \frac{\partial z}{\partial W}$$

    • 每一层神经元只需要计算并存储本层的局部导数（Local Gradient），当上层传下来一个误差梯度时，将它与自己的局部导数相乘，就能继续往前传给更底层的网络。这种动态规划的思想避免了重复计算，将训练复杂度控制在线性阶。

    多层感知机的梯度计算

    • 令$$\ell(\theta, x, y)$$表示单个数据上的损失，则整个数据集 D 上的总损失

    $$ \mathcal{L}(\theta, D) = \sum_{i=1}^m \ell(\theta, x_i, y_i)$$

    • 令$$\theta ^ {(\ell)}$$表示第$$\ell$$层的参数（包括$$W$$和$$b$$），则有$$ \theta = (\theta^{(1)}, \dots, \theta^{(L)})$$

    • 仅需考虑单个数据上的$$ \nabla \ell(\theta, x, y)$$

    • 梯度$$ \nabla \ell(\theta, x, y)$$等价于$$\frac{\partial \ell(\theta, x, y)}{\partial \theta^{(\ell)}},\ \forall \ell \in [L]$$
    • 对于输出层$$\ell=L $$，可得$$ \frac{\partial \ell(\theta, x, y)}{\partial \theta^{(L)}} = \frac{\partial \ell(\theta, x, y)}{\partial x^{(L)}} \cdot \frac{\partial x^{(L)}}{\partial \theta^{(L)}}$$
    • 对于倒数第二层$$\ell=L-1$$，可得$$\frac{\partial \ell(\theta, x, y)}{\partial \theta^{(L-1)}} = \frac{\partial \ell(\theta, x, y)}{\partial x^{(L)}} \cdot \frac{\partial x^{(L)}}{\partial x^{(L-1)}} \cdot \frac{\partial x^{(L-1)}}{\partial \theta^{(L-1)}}$$
    • $$ \frac{\partial \ell(\theta, x, y)}{\partial x^{(L)}} $$这一项的计算可复用

    • 越靠前的层，乘积链越长
    • 所有中间项都可以从后往前递推计算

    多层感知机：优化基础

    对于传统机器学习算法，通过经验风险最小化原则转化为优化问题之后，大多可以采用梯度下降法进行求解。其中一个非常关键地因素是那些优化问题通常都是凸优化问题，梯度下降法能够保证收敛到最优解。

    • 凸函数(Convex Fuction): 当函数$$ f(\cdot) : \mathbb{R}^d \mapsto \mathbb{R}$$满足下列条件时，称之为凸函数。

    • 其可行域 dom f 为凸集合，即$$ \alpha x + (1 - \alpha) y \in \text{dom } f,\ \forall \alpha \in [0,1],\ x,y \in \text{dom } f$$

    • $$ \forall \alpha \in [0,1],\ x,y \in \text{dom } f: $$

      $$\quad f\left( \alpha x + (1 - \alpha) y \right) \leq \alpha f(x) + (1 - \alpha) f(y)$$

      函数曲线在任意两点连线的下方。

      函数图像永远在其切线之上。

    • 可微函数$$ f(\cdot) : \mathbb{R}^d \mapsto \mathbb{R}$$是凸函数，当且仅当

    • 其可行域 dom f 为凸集合

    • $$f(y) \geq f(x) + \nabla f(x)^\top (y - x),\quad \forall x,y \in \text{dom } f$$

    • 平滑函数(Smooth Function): 当函数$$ f(\cdot) : \mathbb{R}^d \mapsto \mathbb{R}$$满足下列条件时，称之为$$\beta-$$平滑函数

    ​ $$|\nabla f(x) - \nabla f(y)|_2 \leq \beta |x - y|_2, \quad \forall x, y \in \mathbb{R}^d$$

    ​ 梯度变化量会被输入的变化量控制

    ​ 梯度不能乱跳，斜率变化是可控的。

    凸性：保证全局最优与下降方向的正确

    • 解决了“往哪里走”的问题——负梯度方向是下降方向，且最终能到达全局最优

    平滑性：控制梯度的变化率

    • 解决了“走多快”的问题——它限制了梯度的变化幅度，使我们可以安全地选择步长，并量化收敛速度

    • 无约束凸优化问题 $$\min_{x} f(x)$$

    • 其中 f(x) 是凸函数

    • 迭代式方法：迭代式优化 $$x_{t+1} = x_t + \eta_t \Delta_t$$

    • $$\eta_t $$ 表示步长或学习率

    • $$\Delta_t$$ 表示更新方向

    • 为何是梯度下降？

    • 理想目标：除$$x_t = x^* = \arg\min_x f(x)$$外，$$f(x_{t+1}) < f(x_t)$$

    • 必要条件

    • 反证法

      • $$\left. \begin{aligned} f(x_{t+1}) &\ge f(x_t) + \nabla f(x_t)^\top (x_{t+1} - x_t) \\ \nabla f(x_t)^\top \Delta_t &\ge 0 \end{aligned} \right}$$$$\implies f(x_{t+1}) \ge f(x_t)$$

    • 梯度下降：迭代式优化$$x_{t+1} = x_t - \eta_t \nabla f(x_t)$$

    • $$\eta_t $$表示步长或学习率

    • 梯度下降收敛速率（T表示迭代的总次数）

    • 普通梯度下降：令$$\hat{x}T = \frac{1}{T}\sum{t=1}^T x_t$$，则有$$\eta_t = O\left(\frac{1}{\sqrt{t}}\right)$$$$\implies f(\hat{x}_T) - f(x^*) = O\left(\frac{1}{\sqrt{T}}\right)$$

    • 平滑函数 + 合适步长：如果$$f(x)$$具备$$\beta-$$平滑性，则有$$\eta_t = O\left(\frac{1}{\beta}\right)$$$$\implies f(x_T) - f(x^*) = O\left(\frac{1}{T}\right)$$

    然而，对于多层感知机以及其它深度学习模型的训练，则几乎不再使用梯度下降法。主要有两个原因：一是这类模型的损失函数不再具备凸性；二是深度学习模型通常对于大规模数据，梯度下降法计算开销难以承受。

    • 基于梯度下降的多层感知机参数更新$$\theta_{t+1} = \theta_t - \eta_t \nabla \mathcal{L}(\theta_t, D)$$

    • $$\eta_t $$表示步长或学习率

    • 问题1：$$\nabla \mathcal{L}(\theta_t, D)$$的计算开销过大

    $$\nabla \mathcal{L}(\theta, D) = \sum_{i=1}^m \nabla \ell(\theta, x_i, y_i)$$

    • ImageNet: $$m=1.4*10^7$$

    • 因为计算量大，我们必须用 SGD 来近似梯度，用牺牲一点点准确性的代价，换取训练的可行性。

    • 问题2：$$\mathcal{L}(\theta, D)$$为非凸函数

    • 梯度下降的非凸优化理论$$|\nabla f(\hat{x}_T)| \leq O\left(\frac{1}{\sqrt{T}}\right)$$，假设函数平滑

    • 基于随机梯度下降的多层感知机参数更新：$$\theta_{t+1} = \theta_t - \eta_t \widetilde{\nabla}\mathcal{L}(\theta_t, D)$$

    • $$\widetilde{\nabla}\mathcal{L}(\theta_t, D) $$（随机梯度）为梯度$$\nabla \mathcal{L}(\theta_t, D) $$的无偏估计，例如均匀采样数据集$$D$$的一个大小为$$m_s << m$$的子集$$D_{m_s}$$

    • $$\widetilde{\nabla}\mathcal{L}(\theta_t, D) = \frac{1}{m_s} \sum_{(x_i,y_i) \in D_{m_s}} \nabla \ell(\theta, x_i, y_i) = \mathbb{E}\left[\nabla \mathcal{L}(\theta_t, D) \mid \theta_t\right]$$
    • $$m_s$$被称为批大小(Batch Size)，每次迭代的时间复杂度从$$O(m)$$降低至$$O(m_s) \approx O(1)$$
    • 对于凸优化问题，随机梯度下降有
      • 凸函数：$$\mathbb{E}\left[f(\hat{x}_T) - f(x^*)\right] = O\left(\frac{1}{\sqrt{T}}\right)$$
    • 对于非凸优化问题，随机梯度下降有
      • 平滑函数：$$\mathbb{E}\left[\left|\nabla f(\hat{x}_T)\right|\right] \leq O\left(T^{-1/4}\right)$$
    • ==非凸情况下的理论保证，要弱于凸情况下的理论保证==
    • ==实践经验：随机性有助于跳出局部最优！==

    架构设计

    多层感知机网络只考虑了相邻层的神经元之间两两都连接的情况，这种层也被称为全连接层(Fully Connected Layer)。实践中根据任务的不同，通常需要设计和利用不同类型的层。

    • 典型的卷积神经网络CNN

    • 卷积层(Convolutional Layer): 用局部感受野 + 权值共享提取空间特征，大幅减少参数量。

    • 池化层(Pooling Layer): 下采样降维，保留关键特征，无参数需学习。
      • Max Pooling：取窗口最大值，保留边缘信息。

    • 展平层(Flatten Layer): 将 2D/3D 特征图拉成 1D 向量，接入全连接层。

    • 全连接层: 将特征映射到最终输出（分类 / 回归）。

    A. 全局极小值 B. 局部极大值 C. 鞍点 (Saddle Point) D. 拐点

    C

    鞍点在某些截面上是极小，有些是极大
