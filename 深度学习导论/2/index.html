    L3：机器学习基础（二）

    00 机器学习发展概览

    当前机器学习的发展经历了三个主要阶段：统计学习时代 $\rightarrow$ 表征学习时代 $\rightarrow$ 大模型时代 。

    • 假设空间的演变

    • 从百家争鸣（树模型、支持向量机、隐马尔可夫、高斯过程等）逐渐收敛到神经网络一枝独秀 。

    • 学习范式的演变

    • 从单一的传统监督/无监督/强化学习，发展出丰富的多视角、半监督、自监督、对比学3'习，再趋于通过自监督预训练和强化对齐（RLHF）的大一统 。

    • 机器学习的学习范式

    01 监督学习 (Supervised Learning)

    监督学习是指利用包含特征 $x$ 和人工标注标签 $y$ 的数据样本，建立从特征到标签的映射关系 。

    1. 二分类与逻辑回归

    给定数据集 $D={(x_{i},y_{i})}{i=1}^{m}$，其中 $x{i}\in\mathbb{R}^{d}$，$y_{i}\in{-1,+1}$ 。

    • 线性分类器与 0-1 损失：

    • 令$$H = { x \in \mathbb{R}^d : w^\top x + b = 0 }$$表示线性超平面，对于给定$$(x,y)$$,如果$$w^\top x + b > 0 $$则表示H预测x为正类，反之为负类

    • x到线性超平面H的距离如下：$$\frac{|w^\top x + b|}{|w|}$$

    • $$|w^\top x + b|$$越大意味着代表样本离超平面越远，模型预测越 “自信”。

    • 0-1损失：$l_{0/1}(x,y)=\mathbb{I}(y(w^\top x+b)\le0)$ 。

    • 缺陷：0-1 损失函数非凸、不连续，梯度处处为 0 或不存在，无法使用梯度下降优化，且模型无法学到“更自信”的决策边界 。

      （非连续）损失函数在$$y(w^\top x + b)=0$$处发生跳变，导数不存在；

      （非凸）损失函数是分段常数，除了跳变点外，函数值在两个区间里都是固定不变的，梯度处处为 0，梯度下降无法更新参数 w,b。而且只要分类正确，无论离超平面多远，损失都是 0，模型无法学到 “更自信” 的决策边界。

      凸函数：函数图像上任意两点连一条线段，线段都不会低于函数曲线本身。只要函数是凸的，无论从哪个起点开始梯度下降，最终都会走到同一个全局最小值，优化过程稳定、可预测，不会被局部最优 “困住”

    • 逻辑回归 (Logistic Regression)：

    • Sigmoid 映射：引入概率视角，通过 Sigmoid 函数将输出映射到 $(0,1)$，表示属于正类的后验概率：

      • $p(y|x)=\frac{1}{1+\exp(-y(w^\top x+b))}$ 。

      • $ y∈{−1,+1}$，Sigmoid 函数将 $y(w^⊤x+b)$ 映射到 (0,1) 区间，代表样本 x 属于标签 y 的概率。

      当$$y(w^\top x + b)>0$$时，预测正确，$$|w^\top x + b|$$越大，$$P(y|x)$$越接近于1；反之当$$y(w^\top x + b)<0$$时，预测错误，$$P(y|x)$$越接近于0。

    • 互补函数： $$p(-y|x) = 1-p(y|x)$$

    • 数据集D的联合概率（假设样本独立同分布）

      在当前 w,b 下，所有样本的真实标签一起发生的可能性有多大

      $$p({y_i} \mid {x_i}; w, b) = \prod_{i=1}^m p(y_i \mid x_i; w, b) = \prod_{i=1}^m \frac{1}{1 + \exp\left(-y_i(w^\top x_i + b)\right)}$$

      所有样本真实标签的概率相乘。这个式子就是参数 w,b 的似然函数，我们的目标是找到使它最大的 w,b。

    • ==最大对数似然==：目标是最大化所有样本真实标签的联合概率 。

      $$log p({y_i}∣{x_i};w,b)=\sum_{i=1}^m -\log\left(1 + \exp\left(-y_i(w^\top x_i + b)\right)\right)$$

    • ==逻辑损失(Logit loss)==

      • 单样本的逻辑损失定义为：

      $$\ell_{\text{LR}}(x, y) = \log\left(1 + \exp\left(-y(w^\top x + b)\right)\right)$$

      该函数凸且平滑，保证梯度下降能找到全局最优；同时处处可导，适合反向传播。

      逻辑损失是 0-1 损失的凸代理损失，在分类正确时损失趋近于 0，分类错误时损失单调递增。处处可导，适合反向传播 。

      训练目标：$$\min_{w,b} \sum_{i=1}^m \ell_{\text{LR}}(x_i, y_i)$$

    2. 多分类问题

    当类别数 $k>2$ 时，无法直接复用二分类的 Sigmoid 。

    二分类逻辑回归的概率公式： $$p(y|x) = \frac{1}{1 + \exp\left(-y(w^\top x + b)\right)}$$

    为每个类别$$c \in[k]$$维护一个线性超平面，即$H = {x \in \mathbb{R}^d : w_c^\top x + b_c = 0} $

    这个形式依赖于 y∈{−1,+1}，无法直接推广到 k>2 的多分类场景，因为：

    • 给定$$(x,y)$$，若直接对每个类别用Sigmoid函数：$$p'(y = c|x) = \frac{1}{1 + \exp\left(-(w_c^\top x + b_c)\right)}$$
    • 此时$$\sum_{c=1}^k p'(y = c|x) \neq 1$$，不满足概率和为1的公理。二分类的时候等于1是因为只算了一个sigmoid，剩下一个是用1-()得到的，所以是等于1的。但多分类的时候不能这么粗暴分配，不科学。

    • ==Softmax 回归==：

    • 假设概率分布：$p(y=c|x)=\frac{\exp(w_{c}^\top x+b_{c})}{\sum_{c'=1}^{k}\exp(w_{c'}^\top x+b_{c'})}$。分母直接实现了概率归一化。

      • 当 k=2 时，Softmax 回归等价于原始逻辑回归

    • 多分类逻辑损失：$l_{LR}(x,y)=-\log\frac{\exp(w_{y}^\top x+b_{y})}{\sum_{c=1}^{k}\exp(w_{c}^\top x+b_{c})}$ 。

    • ==数据集D的联合概率==：令$$\mathbf{W} = [w_1, \dots, w_k] \in \mathbb{R}^{d \times k},\ \boldsymbol{b} = (b_1, \dots, b_k) \in \mathbb{R}^k$$，有$$p({y_i}|{x_i};\mathbf{W},\boldsymbol{b}) = \prod_{i=1}^m \prod_{c=1}^k \left(p(y_i = c|x_i;\mathbf{W},\boldsymbol{b})\right)^{\mathbb{I}(y_i = c)}$$

    • ==最大对数似然==：令$$\mathbf{W} = [w_1, \dots, w_k] \in \mathbb{R}^{d \times k},\ \boldsymbol{b} = (b_1, \dots, b_k) \in \mathbb{R}^k$$，有$$\log p({y_i}|{x_i};\mathbf{W},\boldsymbol{b}) = \sum_{i=1}^m \sum_{c=1}^k \mathbb{I}(y_i = c) \log p(y_i = c|x_i;\mathbf{W},\boldsymbol{b})$$

    • ==多分类逻辑损失==：（代入 Softmax 函数公式）

      $$\begin{aligned} \ell_{\text{LR}}(x,y) &= -\log \frac{\exp\left(w_y^\top x + b_y\right)}{\sum_{c=1}^k \exp\left(w_c^\top x + b_c\right)} \ &= \log\left(1 + \sum_{c \neq y} \exp\left( (w_c - w_y)^\top x + b_c - b_y \right)\right) \end{aligned}$$

      • （推导）

      • 当 k=2 时，这个式子会退化为二分类逻辑损失$$\ell_{\text{LR}}(x, y) = \log\left(1 + \exp\left(-y(w^\top x + b)\right)\right)$$

      • 性质：凸且平滑，适合梯度下降优化，同时衡量模型对真实类别的置信度。

    • 从多分类向二分类转换：

    • 一对多 (One-Against-Rest)：

      • 考虑k个二分类问题，其中第i个问题将第i类认定为正类，其它为负类
      • 测试时分别应用k个模型，如果模型将其预测为正类，则类别 i 记1票，反之每个其他类别均记1票
      • 最终预测结果为投票或加权投票最高类

      • 缺点
      • 每个分类器均需处理所有训练数据，另外单个分类器可能面临类别不平衡问题

    • 一对一 (One-Against-One)：

      • 考虑$$\binom{k}{2}$$个二分类问题，每个问题从原k类中挑选出2类分别作为正负类

      • 测试时分别应用$$\binom{k}{2}$$个模型，每个模型将票投给它所预测的正类

      • 优缺点

      • 每个分类器仅需处理$$O(2/k)$$的数据

      • 假设：

        • 总共有 k 个类别。每个类别样本数大致相同，总样本数为m。那么每个类别大约有m/k个样本

        • 每个二分类器只处理两个类别的样本，样本总数约为：m/k+m/k=2m/k

        • 所以单个分类器处理的数据量占总数据量 m 的比例是：(2m/k)/m=2/k，即$$O(2/k)$$

      • 不适用于原始数据量较少的场景（如果原始数据总量本来就很少，拆分后每类数据太少，模型根本学不到东西）

    3. 罕见类与数据不平衡

    当数据分布极端不平衡时，单纯追求准确率会导致罕见类被忽略。

    • 类别分布不平衡问题
    • 例子：信用卡欺诈数据中，99% 是正常交易，1% 是欺诈交易。如果模型直接无脑预测为正常，准确率能达到 99%，但完全没识别出欺诈样本，这完全失败的。
    • 即简单的准确率不再能反映真实效果，必须专门关注罕见类的识别。
    • 解决思路：提高罕见类别数据的重要性，让模型更重视罕见类样本，不要被多数类淹没。例如为类别 c 赋予错分代价 C(c)

    ==①样本重加权 (Cost-sensitive Learning)==

    • 为罕见类分配更大的错分代价 $C(c)$，迫使模型重视罕见类。
    • $$C(y_i)$$: 给不同类别分配错分代价。
    • 对罕见类，$$C(y_i)$$设得很大 --> 模型如果分错罕见类，惩罚更重。
    • 对常规类，$$C(y_i)$$设得很小 --> 分错常规类的惩罚较轻。
    • 模型会被迫 “小心” 对待罕见类，避免全部预测为多数类。

    ==②样本重采样==

    • 根据类别罕见程度调整采用概率
    • 采样概率通常与类别错分代价 C(c) 成正比
    • 对罕见类做过采样，对常规类做降采样
    • 极端情况：单边选择
    • 保留罕见类中的所有数据，仅采样一部分常规类数据
    • 根据类别罕见程度调整采样概率
    • 问题：罕见类的过采样可能造成数据重复，让模型过度学习这些重复样本，从而引发过拟合问题

    ==③SMOTE 算法 (合成过采样)==：通过在最近邻罕见样本之间进行线性插值来生成新样本，避免了简单复制样本带来的过拟合问题 。

    为避免重复复制样本带来的过拟合，SMOTE采用合成新样本的方式做过采样（在罕见类样本之间插值合成新样本）

    1. 找邻居：对于每个罕见样本，计算它与其它同类样本之间的距离，从而找到最近的K个同类别邻居样本
    2. 选邻居：从这K个最近邻居中随机选择一个样本，并计算该样本与当前样本的差异
    3. 算差异&合成新样本：根据差异比例，从这两个样本连成的线段中生成一个新的合成样本
    4. 重复上述过程，直至生成指定数量的合成样本

    4. 经典机器学习模型与评估指标

    在进入神经网络之前，传统的强大假设空间不可忽视：

    • 支持向量机 (SVM)：寻找一个能将两类数据分开，且“间隔 (Margin)”最大的超平面。通过核技巧 (Kernel Trick)，SVM 可以将数据映射到高维空间，从而解决非线性分类问题。
    • 决策树与集成学习：
    • 决策树 (Decision Tree)：基于特征对数据进行递归切分（如基尼系数、信息增益）。
    • 随机森林 (Random Forest)：构建多棵决策树并进行投票，属于 Bagging 集成。
    • 梯度提升树 (GBDT/XGBoost)：后一棵树拟合前一棵树的残差，属于 Boosting 集成。
    • 核心评估指标 (Metrics)：
    • 精确率 (Precision)：预测为正的样本中，真实为正的比例。
    • 召回率 (Recall)：真实为正的样本中，被正确预测出来的比例。
    • F1-Score：精确率和召回率的调和平均，是不平衡数据分类的重要指标。

    02 无监督学习 (Unsupervised Learning)

    与监督学习不同，在无监督学习中，给定的数据样本属性中仅包含特征x，没有经人工标注的标签y，模型因此需要从数据的内在结构或分布中进行学习。

    聚类，降维，有一定主观色彩

    1. K-Means 算法

    K-Means算法是最经典的聚类算法

    • 目标 (损失函数)：最小化簇内平方和 (SSE)：$$G_{\text{k-means}}\big((\mathcal{X}, d), (C_1, \dots, C_k)\big) = \sum_{i=1}^k \sum_{x \in C_i} d\big(x, \mu_i(C_i)\big)^2$$。即让簇内样本尽量紧凑。

    $$d\big(x, \mu_i(C_i)\big)$$：样本x到第i个簇中心$$\mu_i$$的距离（通常是欧式距离$$|\boldsymbol{x} - \boldsymbol{\mu}i|^2$$），Ci即为第i个簇。即为$G{k-means}=\sum_{i=1}^{k}\sum_{x\in C_{i}}||x-\mu_{i}||^{2}$

    $$\mu_i(C_i)$$：第i个簇的均值（质心），即$$\mu_i = \frac{1}{|C_i|} \sum_{\mathbf{x} \in C_i} \mathbf{x}$$

    • 把所有样本分到 k 个簇里，让每个样本到自己簇中心的距离平方之和最小，也就是 “簇内样本尽量紧凑”。

    • 算法流程：

    • 随机初始化 $k$ 个质心 $$\mu_1, \dots, \mu_k$$。

    • 分配簇：将样本分配到最近的质心。此步骤不会增加损失。
    • 更新质心：将质心更新为该簇样本的均值。此步骤同样不会增加损失。

    • 重复直到收敛。

    • 特性：只能保证收敛到==局部极小值==，因此随机初始化非常重要（比如多次随机初始化选最好的结果）。

    • K-Means可以成功的原因：

    • 算法的每一步迭代优化都不会增加损失，因此必然收敛到一个局部极小值.

    2. 主成分分析 (PCA)

    Principal Component Analysis

    • 动机：当特征维度之间存在一定相关性时，不需要保留所有维度，可以把数据投影到方差最大的方向，实现降维。

    • 坐标轴旋转

    • 对于向量$$x = (x^{(1)},...x^{(d)}) \in \mathcal{R}^d$$，一般考虑标准坐标系$$x = x^{(1)} e_1 + x^{(2)} e_2 + \dots + x^{(d)} e_d$$

    • 对于任意单位正交坐标系$${w_1, w_2, \dots, w_d}$$(单位正交基)，令$$W = [w_1, w_2, \dots, w_d]$$，则有$$\begin{aligned} x &= W W^\top x = \left( \sum_{i=1}^d w_i w_i^\top \right) x = \sum_{i=1}^d w_i (w_i^\top x) \ &= (w_1^\top x) w_1 + (w_2^\top x) w_2 + \dots + (w_d^\top x) w_d \end{aligned}$$

      因为$${w_i}$$是正交基，所有任何向量x都可以唯一表示为：$$x = \sum_{i=1}^d \alpha_i w_i$$

      所以$$ \alpha_i$$是x在$$w_i$$上的新坐标。利用正交性：

      $$w_j^\top x = w_j^\top\left( \sum_{i=1}^d \alpha_i w_i \right) = \alpha_j (w_j^\top w_j) = \alpha_j$$（因为$$ w_j^\top w_j=1$$，其他所有项$$ w_j^\top w_i$$都是0）

      所以$$\alpha_j = w_j^\top x$$，代回去就得到：$$x = \sum_{i=1}^d (w_i^\top x) w_i$$

      写成矩阵形式：$$x = W W^\top x$$，其中$$W = [w_1, w_2, \dots, w_d]$$

    • 得到旋转后的新坐标$$y = (w_1^\top x, \dots, w_d^\top x)$$

    • PCA的目标：找到一组正交向量，让样本在这些向量上的投影方差最大（方差大=信息多，因为样本在这个方向上分布更分散，差异大，能区分不同样本）。

      • 新坐标：对每个样本$$x_i$$，投影为$$y_i = (w_1^\top x_i, \dots, w_k^\top x_i)^\top$$

    • 给定数据集$$D = {x_i}_{i=1}^m,\quad x_i \in \mathbb{R}^d$$

    • 算出一组单位正交向量$${w_1, w_2, \dots, w_k}$$，使得$${x_i}_{i=1}^m$$在这些向量上对应的新坐标方差最大

    新坐标：$$\left{ y_1 = \begin{bmatrix} w_1^\top x_1 \ w_2^\top x_1 \ \vdots \ w_k^\top x_1 \end{bmatrix},\ y_2 = \begin{bmatrix} w_1^\top x_2 \ w_2^\top x_2 \ \vdots \ w_k^\top x_2 \end{bmatrix},\ \cdots,\ y_m = \begin{bmatrix} w_1^\top x_m \ w_2^\top x_m \ \vdots \ w_k^\top x_m \end{bmatrix} \right}$$

    为了降维，一般$$k \ll d$$。只保留前 k 个方差最大的方向。

    • 一维PCA

    • $${x_i}_{i=1}^m$$的新坐标$$w_1^\top x_1 + w_1^\top x_2 + \dots + w_1^\top x_m$$

    • 令$$\bar{x} = \frac{1}{m}\sum_{i=1}^m x_i$$，则均值为$$\mu = w_1^\top \bar{x}$$，方差为$$\begin{aligned} \frac{1}{m}\sum_{i=1}^m (w_1^\top x_i - w_1^\top \bar{x})^2 &= \frac{1}{m}\sum_{i=1}^m w_1^\top (x_i - \bar{x})(x_i - \bar{x})^\top w_1 \ &= w_1^\top \left( \frac{1}{m}\sum_{i=1}^m (x_i - \bar{x})(x_i - \bar{x})^\top \right) w_1 \end{aligned}$$

    • 优化问题 $$\max_{w \in \mathbb{R}^d} w^\top C w \quad s.t. \ |w|^2 = 1$$

      这里$$C = \frac{1}{m}\sum_{i=1}^m (x_i - \bar{x})(x_i - \bar{x})^\top$$表示协方差矩阵

    • 求解

      • 构造拉格朗日函数：$$-w^\top C w + \lambda(|w|^2 - 1)$$
      • 对 w 求导，并令导数等于0，可得$$-2Cw + 2\lambda w = 0 \iff Cw = \lambda w$$
      • 协方差矩阵最大特征值 $$\max_{w \in \mathbb{R}^d} w^\top C w = \lambda w^\top w = \lambda$$

    • k维PCA

    • 优化问题：$$\max_{W \in \mathbb{R}^{d \times k}} \text{trace}(W^\top C W) \quad s.t. \ W^\top W = I$$，这里$$C = \frac{1}{m}\sum_{i=1}^m (x_i - \bar{x})(x_i - \bar{x})^\top$$仍表示协方差矩阵
    • 求解：$$W = [w_1, \dots, w_k]$$，其中$$w_k$$表示C的第k大特征值对应的特征向量
    • 信息量：$$\frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i}$$，其中$$\lambda_i$$表示C的第i大特征值，也等于第i个新坐标的方差

    • 数学求解：

    • 寻找正交投影矩阵 $W$，使得投影后的坐标方差最大。

    • 最终转化为求解数据协方差矩阵 $C$ 的特征值分解：$Cw = \lambda w$。

    • 第 $i$ 个主成分的方向即为第 $i$ 大特征值对应的特征向量，其特征值 $\lambda_i$ 即为该方向上的方差（信息量）。

    • 降维维度的选择：通过计算信息量占比 $\frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i}$ 来决定保留多少维度 $k$。

    03 弱监督与迁移学习

    弱监督学习是一类标签信息不完整/不精确/不准确的学习范式，和 强监督学习（Full Supervision，每个样本都有精确标签）相对，主要分为三类：

    类别 英文 核心问题 典型子方向
    不完整监督 Incomplete Supervision 只有部分样本有标签，大部分无标签 半监督学习、主动学习
    不精确监督 Inexact Supervision 标签是粗粒度 / 包级别的，不是样本级精确 多示例学习（Multi-instance Learning）
    不准确监督 Inaccurate Supervision 标签存在噪声、错误 带噪标签学习（Learning with Noisy Label）
    • 半监督学习：属于不完整监督，利用无标签数据辅助训练。
    • 主动学习：同样属于不完整监督，模型主动选择最有价值的无标签样本请求人工标注，高效利用标注资源。
    • 多示例学习：样本以包（Bag）为单位，一个包包含多个实例，仅知道包的标签，不知道具体哪个实例对应标签。
    • 带噪标签学习：处理标签中存在错误的情况，让模型在噪声数据中仍能学习到有效规律。

    半监督学习

    在实践中，标签数据难以获取，但是往往拥有很多无标签数据，并且有助于我们估计数据的内在结构或者特征之间的联合分布。

    • 半监督学习核心是利用少量有标签数据（Labeled Data）+大量无标签数据（Unlabeled Data） 共同训练模型，解决实际场景中“标签获取成本高、无标签数据易得”的问题。

    • 有标签数据（L）：提供监督信号，帮助模型学习基础分类/回归规则。

    • 无标签数据（U）：帮助模型捕捉数据的内在结构、特征联合分布，让决策边界更贴合真实数据分布。

    • 对比纯监督学习：仅用少量标签数据时，决策边界可能很粗糙；加入无标签数据后，边界能更准确地拟合数据分布。

    • ==伪标签==

    1. 初始训练：用少量有标签数据（L）训练一个基础分类器。
    2. 预测无标签数据：用训练好的分类器对无标签数据（U）进行预测，得到每个样本的类别置信度。
    3. 筛选高置信样本：挑选置信度 Top-k 的无标签样本，将模型预测结果作为它们的 “伪标签”。
    4. 扩充训练集：把这些带伪标签的样本从 U 移到 L 中，和原始有标签数据一起重新训练分类器。
    5. 迭代优化：重复上述步骤，逐步扩充有标签数据集，提升模型性能。

    即利用少量有标签数据和大量无标签数据共同训练。

    伪标签 (Pseudo-labeling)：用基础模型预测无标签数据，挑选置信度最高的样本作为伪标签加入训练集迭代。

    主动学习

    除了直接利用无标签数据之外，在标签数据稀缺的情况下可以通过主动学习(Active Learning)去挑选最具“价值”的无标签数据，并为其添加标签。

    主动挑选最有 “价值” 的无标签样本，请求人工标注，再用这些高质量标注样本优化模型，用最少的标注成本获得最好的模型性能。

    • 关键问题

    • 在给定代价的情况下，如何挑选样本使得模型的性能最好？

    • 思路1：不确定性采样（Uncertainty Sampling）

    • 为模型当前预测标签最不确定的样本打标签

      模型对某个样本的预测越模糊、越没把握，说明这个样本处于决策边界附近，能帮助模型修正边界、提升区分能力。

      • 比如二分类任务中，模型预测某样本为正类51%，负类49%，这就是高度不确定的样本，优先标注。若预测为正类99%，则模型很确定，标注价值低。

      • 线性模型下的不确定性度量：

      • 样本到线性超平面的距离$$\frac{|w^\top x + b|}{|w|}$$（距离越小越不确定）

      • 其他度量方式：

    • 思路2：期望误差缩小(Expected Error Reduction)

    更贪心一点orz

    直接目标是挑选能让模型在未来测试集上误差最小的样本，但计算复杂度很高，所以会做多层近似。

    • 注意不是找“现在误差最小”的样本，而是标注它之后，未来整体误差会变得最小的样本

    • 令U表示未打标签的数据集合

    • 理想目标：从 U 中选样本 x，让模型在剩余样本上的预测误差最小。

      • 问题：需要训练新模型并评估误差，计算量极大，几乎不可行。

    • 第一次近似：从U中挑选样本使模型在剩余样本上的标签不确定性最小

      • 问题：不够精准

    • 第二次近似：从U中挑选样本使模型在剩余样本上的==期望标签不确定性(EER)==最小

      标签不确定性：只看当前模型对 z 有多迷糊

      期望标签不确定性：假设标注 x，预测未来所有 z 平均有多迷糊

      Eg.

    • 对于候选未标签数据 $$x \in U$$，令$$P_i(x)$$表示其标签为 $$i$$ 的后验概率（Posterior Probability）

    • 对于 $$z \in U$$，令$$P_j^{(x,i)}(z)$$表示 $$(x,i)$$ 加入训练集合后 $$z$$ 的标签为 $$j$$ 的后验概率
    • 期望标签不确定性 $$E(x, z) = \sum_{i=1}^k P_i(x) \left( \sum_{j=1}^k \sum_{z \in U} \left| P_j^{(x,i)}(z) - 0.5 \right| \right)$$
    • $E(x,z)$ 越大越好

    总结：不完整监督 (Incomplete Supervision)

    只有部分样本有标签，大部分无标签。

    • 半监督学习 (Semi-supervised)：利用少量有标签数据和大量无标签数据共同训练。经典方法是伪标签 (Pseudo-labeling)：用基础模型预测无标签数据，挑选置信度最高的样本作为伪标签加入训练集迭代。
    • 主动学习 (Active Learning)：模型主动挑选最有“价值”的样本请求人工标注。
    • 不确定性采样 (Uncertainty Sampling)：挑选模型当前预测最不确定（如二分类预测概率接近 50%）的样本。
    • 期望误差缩小 (EER)：挑选标注后能使模型在未来测试集上整体期望误差最小的样本。

    多实例学习

    • 数据不是单个样本（instance），而是被打包成包（bag），一个包包含多个实例。

    • 标签只给整个包，不给包里每个实例的单独标签。

    • 目标：通过包级标签，学习到能对包 / 实例进行分类的模型。

    • 假设：

    • 负包（Negative Bag）：包里所有实例都是负样本（标签 - 1）。

    • 正包（Positive Bag）：包里至少有一个正样本（标签 + 1），这个正样本被称为见证者（witness）。

    • 单实例学习（Single Instance Learning）：每个点都有标签，直接学习决策边界。

    • 多实例学习（Multi-instance Learning）：只有包的标签，需要从包的集合中推断实例和边界。

    总结：不精确监督 (Inexact Supervision) - 多实例学习

    数据以“包 (Bag)”为单位，标签打在包上，而非包内的实例上。

    • 假设：负包中所有实例都是负样本；正包中至少有一个正样本（见证者 Witness）。
    • 应用场景：医疗影像（整张切片标定癌症，无需圈出具体细胞）、药物发现、文本级情感分类。

    噪声标签

    不准确监督

    打标过程中的失误，会导致训练集中的数据有的是错误打标的，即噪声标签。

    解决噪声标签的问题可以从提升模型对噪声的鲁棒性、选用鲁棒的损失函数、以及添加正则项的方法来进行。

    训练集标签存在错误。解决方案包括 ：

    • 噪声适应层：在模型末端增加一层，建模“真实标签被错标为噪声标签的概率” 。
    • 自信惩罚项 (Confidence Penalty)：在损失函数中增加信息熵惩罚（最大化熵），避免模型对错误标签过度自信（把错误标签学“死”） 。

    迁移学习 (Transfer Learning)

    核心是利用已有领域/任务的知识，提升新领域/任务的学习效果，解决 “目标域数据少、任务复杂” 的问题。

    • 给定源域$$D_s$$和学习任务$$T_s$$，以及目标域$$D_T$$和学习任务$$T_T$$，迁移学习旨在利用$$D_s$$和$$T_s$$的知识改进$$D_T$$和$$T_T$$上的学习效果，其中$$D_s \neq D_T$$或者$$T_s \neq T_T$$

    • 根据源数据和目标数据的标签关系可进行如下分类

    • ==微调（Fine-tuning)==

    • 预训练模型$$\theta_s$$：在大规模通用数据上提前训练好的模型（如 BERT、ResNet、Qwen 等），已经学到了通用特征（如文本语义、图像边缘）。

    • 利用预训练模型做初始化，在目标域数据 $D_T$ 用梯度下降最小化目标任务损失

      $$\theta_{T,0} = \theta_S \qquad \theta_{T,t+1} = \theta_{T,t} - \eta_t \nabla_\theta \mathcal{L}(\theta_{T,t}, D_T)$$

    • 实践技巧(Tricks):

      • 尝试较小的学习率$$\eta_t$$(防止参数更新过猛)，以及不同（层）参数使用不同的$$\eta_t$$
      • 冻结部分参数，利用深度神经网络的前几层
      • 最后一层重新初始化
      • ...

    • ==多任务学习(Multi-task Learning, MTL)==

    同时训练多个相关任务，利用任务间的共享知识互相提升。

    • 标准设定：给定n个学习任务以及相应的数据$$D_1,...,D_n$$，目标是找到一个共享参数的模型，最小化所有任务的损失和：
      • $$\min_{\theta} \sum_{i=1}^n \mathcal{L}_i(\theta, D_i)$$
    • 严格来说，MTL 不属于迁移学习，因为后者通常假设$$D_s$$未知

    • 反之，迁移学习可以用于实现MTL

    总结：迁移学习

    迁移学习：利用源域/源任务知识提升目标域/目标任务效果，前提是领域或任务不完全相同 。

    • 微调 (Fine-tuning)：在大规模通用数据上预训练模型，然后在目标任务上使用较小的学习率调整参数（或冻结底层参数只训练顶层） 。
    • 多任务学习 (MTL)：同时并行训练多个相关任务，共享底层特征，利用任务间的共享知识互相提升，不存在明确的 “源$\to$目标” 方向。

    04 强化学习简介 (Reinforcement Learning for LLM)

    主要用于大语言模型（LLM）的对齐和复杂推理优化。

    1. PPO (Proximal Policy Optimization)

    近端策略优化

    • 核心思想：“小步更新，稳定训练”。通过截断操作（Clip）限制新旧策略的差异幅度，防止模型训练崩溃。
    • ==优势函数==估计 ($\hat{A}_t$)：通过独立的批判模型（Critic）评估当前动作比“平均预期水平”好多少。好的多做，差的少做。
    • 训练流程：待对齐模型生成动作 $\to$ 奖励模型打分 $\to$ Critic 模型计算优势 $\to$ 使用 PPO 损失同时更新对齐模型和 Critic 模型。

    2. GRPO (Group Relative Policy Optimization)

    GRPO 是 PPO 的改进版，专门针对大语言模型（LLM）的复杂任务（如数学题、代码题）优化，核心是分组相对奖励 + 简化训练流程。

    专门针对大模型复杂推理（如 DeepSeek 采用的数学/代码任务优化）设计的轻量化算法。

    • 核心改进：放弃了独立的 Critic 批判模型，极大地节省了显存和训练流程。
    • 分组相对奖励：针对同一个问题，让模型生成多个候选答案（如 $3 \sim 5$ 个分组），直接计算组内答案的相对奖励（减去均值，除以标准差），以此作为优势估计。
    • KL 散度约束：限制新策略偏离参考模型（预训练模型）太远，防止大模型在强化学习中出现“对齐税（变笨）”或“跑偏”。

    在多分类问题中，如果直接使用 $k$ 个二分类器进行“一对多 (One-Against-Rest)”策略，最容易面临的问题是：

    A. 无法处理非线性问题 B. 类别严重不平衡 C. 训练速度比一对一策略快 D. 无法使用梯度下降

    B

    A 选项：一对多（OvR）使用的基二分类器本身可以处理非线性问题（比如核 SVM、非线性逻辑回归），所以它不是 OvR 面临的特有问题，A 错误。

    B 选项：==OvR 为每个类别训练一个分类器，训练时把当前类别作为正类，其余所有 k-1 类都合并作为负类，这会导致正样本数量远少于负样本，出现严重的类别不平衡，这是 OvR 最典型、最容易出现的问题，B 正确。==

    C 选项：“训练速度比一对一快” 是 OvR 的优点，不是它面临的问题，C 不符合题意。

    D 选项：OvR 的基二分类器（如逻辑回归）完全可以用梯度下降优化，不存在无法使用梯度下降的限制，D 错误。

    在处理严重不平衡数据（如 99% 正常，1% 欺诈）时，以下哪种评价指标比“准确率 (Accuracy)”更具参考价值？

    A. F1-Score B. 误差平方和 (SSE) C. 方差 D. 交叉熵

    A

    A. F1-Score：F1-Score 是精确率和召回率的调和平均数，专门用于不平衡分类任务。比如 99% 正常、1% 欺诈的场景，无脑预测全部正常就能拿到 99% 的高准确率，但完全没识别出欺诈；F1-Score 能兼顾少数类（欺诈样本）的识别效果，比准确率更有参考价值。

    B. 误差平方和 (SSE)：多用于回归任务，不适合分类的不平衡数据评价。

    C. 方差：是描述数据离散程度的统计量，不是分类模型的评价指标。

    D. 交叉熵：常作为分类任务的损失函数用于训练优化，不是用来直观衡量不平衡模型表现的评价指标。

    在 PCA 中，第 $i$ 个主成分的方向对应于数据协方差矩阵的：

    A. 第 $i$ 大的特征值对应的特征向量 B. 最小的特征值对应的特征向量

    C. 随机生成的正交向量 D. 均值向量

    A

    对数据的协方差矩阵做特征值分解，特征值从大到小排序，第 1 主成分对应最大特征值的特征向量（数据方差最大的方向），第 2 主成分对应第 2 大特征值的特征向量，以此类推，第i个主成分就对应第i大的特征值所对应的特征向量。

    • A 选项：符合上述原理，正确。
    • B 选项：最小特征值对应的是方差最小的方向，不是靠前的主成分方向，错误。
    • C 选项：主成分是通过协方差矩阵特征分解得到的，不是随机生成的正交向量，错误。
    • D 选项：均值向量是数据平移的依据，和主成分方向无关，错误。

    随机森林 (Random Forest) 属于哪种集成学习范式？

    A. Boosting B. Bagging C. Stacking D. Cascade

    B

    随机森林（Random Forest）是Bagging范式的典型代表：

    它通过对训练集自助采样（行采样）、对特征随机子空间采样（列采样），并行训练多棵独立决策树，最后通过投票 / 平均得到结果，符合 Bagging 并行构建基学习器、降低方差的特点。

    Boosting 是串行迭代优化（如 GBDT、AdaBoost）；Stacking 是分层堆叠学习；Cascade 是级联结构，都不符合随机森林的机制。

    梯度提升树 (GBDT) 在训练下一棵决策树时，其拟合的目标通常是：

    A. 原始标签 B. 数据的方差 C. 前一轮模型的残差（或负梯度） D. 随机采样的特征

    C

    梯度提升树（GBDT）属于 Boosting 类算法，每一轮迭代会计算前一轮模型损失函数的负梯度（近似残差），让下一棵决策树去拟合这个负梯度，逐步修正之前模型的误差，累加所有树的结果得到最终预测。

    不是直接拟合原始标签、数据方差，也不是采样特征。

    逻辑回归的损失函数（交叉熵/Logit loss）是凸函数，这意味着：

    A. 梯度下降可能会陷入局部最优 B. 任何局部极小值都是全局最小值

    C. 它的二阶导数矩阵（海森矩阵）存在负特征值 D. 损失曲线是不连续的

    B

    A 选项：==凸函数的优化不存在局部最优陷阱==，梯度下降只要步长合适能收敛到全局最优，不会陷入局部最优，A 错误。

    B 选项：==凸函数的重要性质就是所有局部最小值都是全局最小值==，这是凸优化的核心特点，B 正确。

    C 选项：凸函数的海森矩阵是半正定的，特征值都≥0，不存在负特征值，C 错误。

    D 选项：逻辑回归的交叉熵损失是连续且可导的光滑函数，损失曲线连续，D 错误。

    为了让模型在带有噪声标签的数据上不要“过度自信”，常在损失函数中加入的正则项是：

    A. L1 正则化 B. 自信惩罚项 (如最大化信息熵) C. Dropout D. 动量

    B

    A. L1 正则化：作用是约束参数权重、产生稀疏参数，侧重降低模型参数复杂度，不是专门抑制标签噪声下的预测过度自信。

    B. 自信惩罚项 (如最大化信息熵)：==最大化输出概率的信息熵，会让模型输出的类别概率分布更平滑，避免模型给出接近 0/1 的极端置信预测==，能有效防止在噪声标签上过度自信，这类惩罚项可以直接加在损失函数里。

    C. Dropout：是网络结构层面的正则手段，训练时随机丢弃神经元，不属于添加在损失函数里的正则项。

    D. 动量：是优化器的迭代加速策略，不是损失函数的正则项，也不直接解决预测过度自信的问题。

    “期望误差缩小 (EER)”策略在主动学习中非常有效，但其最大的缺点是：

    A. 准确率低 B. 计算复杂度极高，需要多次重新训练模型来评估

    C. 容易过拟合 D. 只能用于回归问题

    B

    它要预估给候选无标签样本标注不同可能标签后、模型重新训练产生的未来误差，以此选出能让期望误差下降最多的样本。这个过程需要遍历候选样本、枚举可能标签、多次重训模型来评估误差，计算开销极大。

    决策树节点分裂时，常用的纯度衡量指标不包括：

    A. 信息增益 (Information Gain) B. 基尼不纯度 (Gini Impurity) C. 均方误差 (MSE) D. 欧氏距离

    D

    A. 信息增益：ID3 算法使用的节点纯度衡量指标，基于熵来判断分裂效果。

    B. 基尼不纯度：CART 分类树使用的纯度指标，数值越小代表节点纯度越高。

    C. 均方误差（MSE）：CART 回归树使用的纯度衡量指标，用来衡量样本离散程度。

    D. 欧氏距离：是衡量两个样本空间距离的指标，不会用于决策树节点分裂的纯度判定。

    深度学习时代，让机器“自学”最主流的无监督学习方法是：

    A. K-Means 聚类 B. 自监督学习 C. 主成分分析 D. 隐马尔可夫模型

    B

    A. K-Means 聚类：是传统经典的无监督聚类算法，但不是深度学习时代最主流的机器 “自学” 方案。

    B. 自监督学习：依托数据自身构造监督信号，让模型从海量无标注数据自主学习特征，是深度学习阶段无监督 / 类无监督自学的主流范式，符合题意。

    C. 主成分分析（PCA）：传统线性降维无监督方法，深度学习中很少作为主流自学框架使用。

    D. 隐马尔可夫模型：传统时序无监督模型，并非深度学习时代主流自学方法。

    损失函数对比：在二分类问题中，为什么我们不能直接使用 0-1 损失函数来更新神经网络的权重？逻辑回归是如何解决这个问题的？

    0-1 vs 逻辑回归：0-1 损失是分段阶跃函数，不连续、非凸、几乎处处梯度为 0，反向传播无法更新参数。逻辑回归引入 Sigmoid 将离散跳变转化为连续概率，使用可导、凸的逻辑损失（交叉熵），保证了梯度下降能找到全局最优。

    多分类策略对比：简述多分类问题中“一对多 (One-Against-Rest)”与“一对一 (One-Against-One)”策略的区别。如果在类别极多且每类数据量极少的情况下，哪种策略更容易出问题？为什么？

    OvR vs OvO：OvR 训练 $k$ 个模型（每个区分一类和其余所有类），易导致正负样本严重不平衡；OvO 训练 $k(k-1)/2$ 个模型（每两个类建一个）。极少数据下，OvO 拆分后每组数据量更小，模型极易学不到东西（欠拟合）。

    不平衡数据处理：简述 SMOTE 算法生成新样本的具体步骤，并说明为什么它比单纯的“随机复制罕见样本（过采样）”更好。

    SMOTE：找同类最近邻 $\to$ 在连线上随机插值生成新样本。纯复制会导致模型死记硬背（过拟合）少数类样本；SMOTE 扩大了决策边界的泛化区域。

    无监督降维机制：PCA 是如何通过正交变换实现降维去噪的？（请从“方差”或“特征值”的角度进行通俗解释）

    PCA机制：寻找一组正交基，将数据投影上去。优先选择投影后数据分布最分散（方差最大）的方向，因为方差大代表保留的区分信息多。对应数学上协方差矩阵的最大特征值及特征向量。特征值小的方向被视为噪声丢弃。

    半监督与主动学习的区别：两者都面对“少量有标签 + 大量无标签”数据，请阐述半监督学习（如伪标签法）与主动学习在利用无标签数据上的核心差异。

    半监督 vs 主动：半监督是让机器自己估算无标签数据的值（伪标签）并加入训练，不需要人；主动学习是让机器筛选最拿不准的样本，请求人类专家去打真实的标签，需要人参与但效率极高。

    主动学习策略：在主动学习中，“不确定性采样”和“期望误差缩小 (EER)”这两种策略有什么区别？为什么实际工程中很少直接采用纯粹的 EER 策略？

    不确定性 vs EER：不确定性只看当前模型对某个样本有多迷糊；EER 看的是“如果标注了这个样本，未来对全局的预测误差能降多少”。EER 不常用是因为计算量灾难（需要穷举所有可能性并频繁重训练模型）。

    弱监督机制：什么是多实例学习 (Multi-instance Learning) 中的“见证者 (Witness)”假设？请结合医疗影像（如病理切片查癌细胞）举例说明。

    Witness假设：包只要被打上正标签，里面必定至少藏着一个正实例（见证者）；只要全是负实例，包就是负的。例如：一张肺部 CT 图像（包）只要有一小块阴影是癌变（见证者），整张图就判定为患癌。

    强化学习对齐 (PPO)：在 PPO 算法中，优势函数 $\hat{A}_t$ 的正负代表什么物理含义？损失函数中的 clip 截断操作起到了什么关键作用？

    PPO核心：$\hat{A}_t > 0$ 说明该动作比预期好，增加其概率；$< 0$ 说明比预期差，降低概率。clip 截断的作用是防止模型为了贪图某次高奖励，把策略参数更新得太猛导致破坏了原本稳定的模型（保证信任域）。

    大模型强化前沿 (GRPO)：为什么最近的大语言模型（如 DeepSeek-R1）在训练复杂推理任务时，倾向于使用 GRPO 算法而不是标准的 PPO？

    GRPO 优势：1. 省去 Critic 批判模型，内存占用和计算量大幅减小，极度适合庞大的 LLM；2. 组内相对对比，通过对同一个问题生成多个解题思路，在它们内部标准化计算相对奖励，更适合评估复杂多步逻辑（如数学推导）的优劣。
