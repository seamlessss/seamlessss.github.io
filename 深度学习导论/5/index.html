    L6：深度视觉模型（一）

    01 计算机视觉基础

    计算机视觉的核心目标是赋予计算机“看”的能力，即通过观察知道“什么在什么地方”。其在现实中有着广泛的应用，如人脸识别、自动驾驶、医学影像分析等。

    1. 图像的底层表示

    人类眼中的图像是连续的光影，而计算机眼中的图像是一组离散的数字矩阵。

    • RGB 模式：彩色图像由多个通道叠加构成，使用红、绿、蓝三个正交色轴。每个通道以 $0 \sim 255$ 的数值表示颜色强度，三通道组合可生成约 1670 万种颜色（24 位色深）。位深度决定了单通道的强度级数（如 8 位 = 256 级），位深越高色彩越细腻，数据量也越大。
    • HSL 模式：一种更符合人类直觉的色彩表示方式，H (色相) 表示颜色种类，S (饱和度) 表示颜色纯度，L (亮度) 表示明暗程度。

    2. 图像分类任务

    识别图像中样本的语义并输出相应的类别。

    • 难点：视角变化、尺度多变、物体遮挡、不同的光照和照明条件、背景杂乱等。
    • 线性分类器无法做到：图像的特征维度极高，线性分类器的表达能力太弱，面对高度非线性的视觉数据难以学习到有效边界。

    3. 传统图像特征提取

    2000年代初期，在深度学习爆发前，计算机视觉主要依赖专家手工设计的特征提取器：

    • 颜色直方图：统计图像中颜色的分布频率。对旋转和尺度变化具有鲁棒性，但完全丢失了空间结构信息。

    • 梯度直方图 (HOG)：通过计算局部区域的梯度方向分布，捕捉物体的形状与边缘信息。

    • SIFT 特征 (尺度不变特征变换)：

    • 一种经典的局部特征检测算法，它在图像的高斯尺度空间中检测关键点。其对旋转、尺度缩放、亮度变化保持不变性，对视角变化、仿射变化、噪声也保持一定程度的稳定性。

    • 机制：在图像的高斯尺度空间中检测关键点。通过 DoG（高斯差分）金字塔实现尺度不变性，通过主方向分配实现旋转不变性。为每个关键点生成 128 维的梯度方向描述符。

    • 步骤：① 建尺度金字塔 $\rightarrow$ ② 跨尺度寻找稳定极值点 $\rightarrow$ ③ 生成 128 维通用描述符 $\rightarrow$ ④ 跨图匹配。

    • 优势：对旋转、尺度缩放、亮度变化保持不变性，对视角变化、仿射变化、噪声也高度稳定，曾广泛用于图像匹配和三维重建。

    4. 手工特征 vs 端到端深度学习

    • 传统 CV (知识驱动)：依赖专家手工设计特征（SIFT/HOG），通过固定算子提取边缘、纹理等浅层表征，可解释性强但表达能力有限，难以泛化。即：人类告诉机器“看什么”。
    • 深度学习 (数据驱动)：如 CNN/ViT，端到端 (End-to-End) 直接从像素自动学习层次化特征，实现从低级边缘到高级语义的映射。在大规模数据下显著超越手工特征。机器自己学会“看什么”。
    • 本质区别在于：手工特征是知识驱动（人类告诉机器看什么），深度学习是数据驱动（机器自己学会看什么）。

    5. 为什么不用多层全连接网络 (MLP) 处理图像？

    如果强行把图像喂给全连接层，会面临两个灾难性弊端：

    全连接层要求输入为一维向量——需要将图像展平处理。

    ①空间信息丢失：强行将二维图像拉直为一维向量，会导致像素之间的空间邻域关系（即上下左右的相对位置）彻底丢失，网络难以捕捉图像中的局部几何特征 。

    ②参数爆炸：全连接层中的每一个神经元都要与前一层的所有输入相连，当输入维度巨大时，参数量会呈指数级增长 。

    仿生学启示：生物视觉存在“感知野 (Receptive Field)”机制，即神经元只感知局部特征而非全局，为卷积神经网络的局部连接和层次化特征提取奠定了生物学基础。

    02 卷积操作与卷积层

    1. 卷积计算

    • 滑动内积：卷积核（Filter/Kernel）是一个包含权重的矩阵。将卷积核与原始图像的局部区域像素进行对应相乘并累加（点积计算）。卷积核在图像上从左至右、从上至下平滑滑动，形成一张新的二维矩阵，即特征图。

    • 多通道处理：卷积核的深度必须与输入的通道数一致（例如输入是 RGB 3 通道，卷积核也必须是 3 通道）。计算时，卷积核的三个通道分别与图像的红、绿、蓝通道进行卷积，随后将这三个通道的中间结果进行像素级累加，各个通道的内积结果最终会相加合并为一个单一通道的输出。

    • 多卷积核提取：卷积层通过多个卷积核的组合来提取输入数据的不同特征。每个卷积核负责提取特定类型的特征（如边缘、颜色斑点），卷积层则将这些特征整合在一起，形成更高层次的特征表示。

    2. 两大归纳偏置

    Inductive Bias:

    • 局部性 (Locality)：计算范围只看局部，不看全局。

    • 平移不变性 (Translation Invariance)：权值共享 (Weight Sharing)。同一个卷积核在整张图上滑动，权重参数在所有滑动位置保持不变，大幅减少参数量。

    • 权值共享

      假设：如果一个特征在计算某个空间位置(x,y)的时候有用，那么它在计算另一个不同位置(x2,y2)的时候也有用。基于这个假设，可以显著地减少参数数量：在同一卷积层中，一个卷积核负责扫描整张图像，其权重参数在所有滑动位置保持不变。

    3. 控制卷积层的超参数

    • 深度 (Depth, $C_{out}$)：使用的卷积核数量，决定了输出特征图的通道数。

    • 每个卷积核在输入图像中检测一些不同的特征。举例来说，如果第一个卷积层的输入是原始图像，那么在深度维度上的不同神经元将可能被不同方向的边界，或者是颜色斑点激活。

    • 步长 (Stride, $S$)：卷积核每次滑动的像素距离。$S=1$ 提取细腻特征；$S>1$ 跳跃滑动，导致输出特征图成比例减小。

    • 填充 (Padding, $P$)：在输入图像四周补零（Zero-padding）。

    • 在卷积过程中，图像边缘的像素参与计算的次数远少于中心像素，且每次卷积都会导致输出尺寸缩小。为了解决这个问题，我们在输入图像的四周补上一圈额外的像素（通常补0，称为Zero-padding）。

    • 作用：①控制输出尺寸；②防止边缘像素参与计算次数过少，确保边缘特征被充分提取。

    • 偏置 (Bias, $b$)：每个卷积核配有一个可学习的偏置参数，加权求和后统一加上。

    4. 输出维度与参数量计算

    假设输入尺寸为 $C_{in} \times H \times W$，卷积核尺寸为 $K_H \times K_W$，填充 $P$，步长 $S$，输出深度 $C_{out}$：

    • 输出特征图高宽（必须保证结果为正整数，否则无法整齐滑动）：

    $$H' = \frac{H - K_H + 2P}{S} + 1$$

    $$W' = \frac{W - K_W + 2P}{S} + 1$$

    • 参数量计算：

    • 权重矩阵大小：$C_{out} \times C_{in} \times K_H \times K_W$

    • 偏置大小：$C_{out}$
    • 总参数量：$C_{out} \times (C_{in} \times K_H \times K_W + 1)$

    5. 感受野

    输出特征图上的一个神经元，对应到原始输入图像上所能“看到”的像素区域大小。即：输出里的 1 个点，是由输入里多大范围的像素算出来的。

    • 单个 $K \times K$ 卷积核，感受野就是 $K$。
    • 堆叠 $L$ 层步长为 1、尺寸为 $K$ 的卷积核，其原始感受野公式为：$1 + L \times (K - 1)$。

    pytorch实现

    在PyTorch中，nn.Conv2d是构建卷积层最核心且最常用的官方接口，它通过高度工程化的参数封装实现了卷积运算、权重初始化以及计算图的自动构建。

    03 卷积神经网络的演进

    卷积神经网络通常是由四种层构成：卷积层、激活函数层（比如RELU）、池化层、全连接层。

    • 最常见的形式就是将一些卷积层和激活层放在一起，其后紧跟池化层，然后重复如此直到图像在空间上被缩小到一个足够小的尺寸，在某个地方过渡成全连接层，如下图所示：

    标准 CNN 架构：卷积层 $\rightarrow$ 激活函数 $\rightarrow$ 池化层 $\rightarrow \dots \rightarrow$ 全连接层 $\rightarrow$ 输出。

    1. 池化层

    周期性插入在卷积层之间，主要用于下采样降低数据体尺寸。

    • 类型：

    • 最大池化 (Max Pooling)：保留边缘/纹理等最强特征

    • 普通池化(General Pooling)：除了最大汇聚，汇聚单元还可以使用其他的函数，比如平均汇聚（average pooling）或L-2范式汇聚（L2-norm pooling），随机池化等等。

    • 不使用池化：回忆卷积层的维度变化——其本身具有下采样效果。在Striving for Simplicity: The All Convolutional Net（2015）中，提出使用一种只有重复的卷积层组成的结构，抛弃汇聚层。通过在卷积层中使用更大的步长来降低数据体的尺寸。

    • 特点：没有任何可学习的参数。

    • 转移不变性：卷积和池化操作具有转移不变性，即 $Conv(Translate(X)) = Translate(Conv(X))$。图像的特征并不取决于它们在图像中的位置。

    即先操作，后平移和先平移，后操作得到的最终结果是一样的

    • 卷积靠权值共享保证提取一致性；池化靠下采样聚合（弱化绝对位置，强化特征存在性）进一步增强鲁棒性。

    2. LeNet-5 (1990s)

    • 历史意义：第一个成功的卷积神经网络应用，是Yann LeCun在上世纪90年代实现的。它由2个卷积层组成和3个全连接层组成，组合使用卷积层、非线性激活函数和汇聚层（下采样层）。
    • 首次将非线性激活函数(Sigmoid/Tanh)融入CNN，让网络具备非线性拟合能力。
    • 提出了权值共享、局部感受野、下采样这三大CNN设计原则，沿用至今。

    背景：ImageNet 数据集的诞生彻底解决了深度模型因样本不足导致的过拟合问题，开启了深度学习的黄金十年。

    3. AlexNet (2012)

    第一个在 ImageNet 竞赛中击败传统 CV 模型的大型深度网络。包含 5 个卷积层 + 3 个全连接层。

    核心创新：

    • 更深的网络结构。

    • 首次大规模使用 ReLU：解决了深层网络中的梯度消失问题，极大提升了训练速度。

    • 局部响应归一化 (LRN)：在卷积层中，每个卷积核都对应一个特征图，LRN 就是对这些特征图进行归一化。在一定程度避免了过拟合，提高泛化能力。

    • 针对同一空间位置、不同输出通道间的归一化。公式通过除以邻居通道特征的平方和，实现“放大差异、强化竞争”，抑制不活跃的神经元。

    • 引入 Data Augmentation (数据增强) 和 Dropout 强效抗过拟合。

    • 采用多 GPU 分布式并行训练。

    4. VGG 架构

    设计动机：用更小的卷积核，堆更深的网络。

    • 网络特点：统一使用 $3\times 3$ 卷积（步长1，填充1保持尺寸），$2\times 2$ 最大池化（步长2）。

    • 为什么 $3\times 3$ 卷积更好？

    • 3 个 $3\times 3$ 卷积层堆叠，其感受野相当于 1 个 $7\times 7$ 卷积核。

    • 参数量锐减：

      • 假设输入输出通道均为 $C$，3 层 $3\times 3$ 的参数量为 $3 \times (3\times 3\times C\times C) = 27C^2$；而 1 层 $7\times 7$ 的参数量为 $49C^2$。$27C^2 < 49C^2$。

    • 非线性更强：3 层卷积意味着包含了 3 次 ReLU 激活，模型表达能力远超单层 $7\times 7$。

    • VGG网络数据流图

    • 🔵 convolution+ReLU：3×3 卷积 + ReLU 激活，提取特征，保持空间尺寸（步长 1 + 填充 1）
    • 🔴 max pooling：2×2 最大池化（步长 2），下采样缩小尺寸，扩大感受野

    • 🟢 fully connected+ReLU：全连接层 + ReLU，将二维特征转为一维，完成分类

    • 总结：VGG 结构简单、规则，被广泛用作“标准特征提取器”骨架，但参数量依然极其庞大（尤其是末端的全连接层）。

    5. 特殊卷积变体

    $1\times 1$ 卷积：

    • 在空间维度上不改变特征图尺寸，但在通道维度上进行跨通道的线性加权组合，本质上是跨通道的线性特征提取。核心价值在于升维或降维（能够灵活调整特征图的通道数，极大降低参数量），同时自带一次 ReLU 增加非线性。

    • 这种结构被广泛应用于GoogLeNet和ResNet的Bottleneck模块中，是提升网络效率的关键手段。

    在通道维度做了可学习的加权融合，把高维通道压缩成低维新特征。

    扩张卷积

    扩张卷积也被称为空洞卷积或者膨胀卷积，是在标准的卷积核中注入空洞，以此来增加模型的感受野。相比原来的正常卷积操作，扩张卷积多了一个参数： dilation rate，指的是卷积核的点的间隔数量，比如常规的卷积操作dilatation rate为1。

    • 常规卷积：dilation rate = 1，就是普通的 3×3 卷积，没有空洞。
    • 扩张卷积：dilation rate = r，表示卷积核元素之间的间隔数为 r-1。
    • 对于一个大小为k×k、扩张率为r的卷积核，它的等效卷积核大小（也就是实际感受野）为：k+(k−1)×(r−1)
    • 在不增加参数量、不进行池化下采样（不丢失空间分辨率）的前提下，大幅扩大感受野。

    6. GoogLeNet

    传统 CNN 的痛点是只能人工固定选择卷积核大小。GoogLeNet 破局思路：拓宽网络，多尺度并行。

    • Inception 模块：将 $1\times 1$、$3\times 3$、$5\times 5$ 卷积和 $3\times 3$ 池化并行放在同一层。让网络自己学习不同尺度特征的权重，“自己决定用哪个”。

    不同尺度特征同时提取，网络自己决定“用哪个”

    • 计算量优化：在进行大卷积（$3\times 3$, $5\times 5$）前，先用 $1\times 1$ 卷积进行降维（例如将参数量从 1.12 亿次降到 530 万次，减少 95% 运算量）。

    • 全局平均池化 (GAP)：在传统的架构（例如 AlexNet）中，末端的全连接层会引入大量参数。GoogLeNet 用全局平均池化层取代了这些全连接层，该层计算每个特征图的平均值（例如，将 7×7 的特征图转换为 1×1 的特征图），这显著减少了模型的参数数量并减轻了过拟合问题。

    • 辅助分类器：

    • 为了解决训练过程中出现的梯度消失问题，GoogLeNet引入了辅助分类器（充当小型分类器的中间分支）。这些辅助分类器仅在训练期间激活，用于帮助规范网络。

    • 结构：

      • 平均池化层（5×5，步长 3）

      • 1×1 卷积（128 个滤波器，ReLU）

      • 全连接层（1024 个单元，ReLU）

      • Dropout层（dropout率=0.7）

      • 全连接softmax层（1000个类别）

    • 核心作用：

      • 缓解梯度消失：中间层直接接损失函数，梯度可以直接回传，让浅层网络有效更新；
      • 正则化网络：辅助分类器相当于给网络加了额外的监督信号，提升模型的泛化能力；
      • 加速训练收敛：让网络在训练早期就能学习到有效特征，加快收敛速度。

    优势

    • 引入了Inception结构，融合不同尺度的特征信息
    • 使用1x1的卷积核进行降维以及映射处理
    • 添加两个辅助分类器帮助训练
    • 丢弃全连接层，使用平均池化层，大大减少模型参数

    7. ResNet

    核心痛点：网络还能继续加深吗？（普通 CNN 堆叠过深会导致退化问题 Degradation——训练误差和测试误差双双飙升，这不是过拟合，而是模型难以优化）。

    • 核心思路：直觉上深模型至少能学得和浅模型一样好（如果新增的层全学成恒等映射 Identity Mapping）。

    • 残差块 (Residual Block)：

    • 不再直接拟合底层映射 $H(x)$，而是拟合残差 $F(x) = H(x) - x$。

      • 使用网络层来拟合残差映射，而不是直接尝试拟合期望的底层映射。

      本质：网络不再学习 “从 x 到 H (x) 的复杂变换”，而是学习 “x 到 H (x) 的差值（残差）”。

    • 引入跳跃连接 (Skip Connection)，直接将输入 $x$ 跨层传递与输出相加：最终输出 $H(x) = F(x) + x$。

    • 为什么有效？

    • 当 $F(x) \to 0$ 时，网络退化为恒等映射，保证深层网络性能保底。

    • 反向传播时，梯度 $\frac{\partial H}{\partial x} = \frac{\partial F}{\partial x} + 1$。因为有 +1 的存在，梯度永远不会完全消失，可以顺畅无损地传导到浅层。

    • 拟合微小的残差扰动比拟合绝对的非线性映射容易得多。

    • 战绩：成功训练出 152 层网络，成为深度学习里程碑。

    8. 现代轻量化与注意力网络

    • SENet (Squeeze-and-Excitation)：引入通道注意力机制。通过显式建模通道间依赖关系，自适应地重新校准特征通道权重的卷积神经网络架构，其核心创新是SE Block——先全局压缩（Squeeze）获取通道统计信息，再通过门控机制（Excitation）学习各通道的重要性并加权增强有用特征、抑制冗余特征。
    • DenseNet：DenseNet (Densely Connected Convolutional Networks) 是一种通过密集连接（每一层都直接与前面所有层相连）实现特征重用和梯度高效传播的卷积神经网络架构。DenseNet在参数和计算成本更少的情形下实现比ResNet更优的性能，也因此斩获 CVPR 2017 的最佳论文奖。
    • MobileNet 系列 (轻量化王者)：
    • MobileNet V1：首创深度可分离卷积 (Depthwise Separable Convolution)。将标准卷积拆分为两步：先按通道单独做空间卷积 (Depthwise)，再用 $1\times 1$ 做跨通道融合 (Pointwise)。参数量和计算量断崖式下降。
    • MobileNet V2：在 V1 的基础上，引入倒残差连接 (Inverted Residual) 和 线性瓶颈层 (Linear Bottleneck)。先 $1\times 1$ 卷积升维扩展特征通道，再深度卷积提取空间信息，最后 $1\times 1$ 降维且不使用 ReLU（防止低维流形经 ReLU 导致信息损毁）。
    • MobileNet V3：结合 V1、V2 特性，并融入 SE 注意力机制和 AutoML 架构搜索。
    • EfficientNet：复合缩放 (Compound Scaling)。联合、平衡地同时放大网络的深度 (Depth)、宽度 (Width) 和分辨率 (Resolution)，以最少的 FLOPs 达到最高精度。
    • Vision Transformer (ViT)：打破 CNN 垄断。将图像切割为固定大小的图块 (Patches)，扁平化后加上位置编码，直接喂给纯 Transformer 编码器。利用全局自注意力机制取代局部卷积。

    04 视觉特征表示与迁移学习

    1. 视觉分类中的特征表示

    为什么要把图像变成单维向量表征？

    • 剔除冗余： 原始像素包含大量背景、光照等无关信息。
    • 语义提炼： 逐层抽象，从“边缘/纹理”变为“眼睛/耳朵”等高级语义。
    • 线性可分： 将复杂的非线性视觉数据，转化为分类器（如全连接层）能够理解和划界的特征空间。

    2. 从边缘、纹理到语义：特征的层次化演化

    • 浅层特征 (细节)：边缘、角点、颜色。感受野小，分辨率高，无语义。
    • 中层特征 (局部)：基础几何形状、物体部件。
    • 深层特征 (整体)：类别宏观模板（狗头、车轮）。感受野极大，空间分辨率低，但语义极其丰富。

    3. 类激活映射 (Class Activation Mapping, CAM)

    • 目的：提供 CNN 的可解释性，可视化模型做决定的“注意力焦点”。
    • 核心方法：
    • 摒弃传统的展平全连接层 (Flatten + FC)，使用全局平均池化 (GAP)
    • 将输出层某个类别（如“狗”）的权重参数，反向投影到最后一层卷积的特征图上，进行加权求和。
    • 现象：发现模型有时会利用背景“作弊”（例如靠雪地背景判断是狼），揭示了数据偏置。

    4. 迁移学习 (Transfer Learning)

    能否提取通用表征——将大数据集上学到的通用知识直接迁移到新任务中。

    现实困难

    • 数据荒：垂直领域（如医疗、工业）很难获取万级以上的标注数据。
    • 算力贵：从零训练大型网络耗时极长，成本极高。

    关键观察

    • 神经网络底层学习的是边缘、纹理等通用视觉特征。迁移学习就是将大数据集上学到的“通用视觉常识”直接搬移到新任务中。

    • 核心原理：CNN 底层学习的是通用的视觉常识（如边缘检测）。我们可以将大规模数据集（如 ImageNet）上学到的预训练权重，直接迁移到新任务中。

    • 三大策略：

    1. 固定特征提取器 (Linear Probing)：冻结卷积骨干网络 (Backbone) 所有参数，只重新随机初始化并训练最后一层全连接层。
    2. 微调 (Fine-tuning)：使用预训练权重初始化，使用极小的学习率在整个网络上端到端继续训练。

    3. 部分冻结：冻结网络底部的浅层通用特征，只微调顶层的高级抽象特征。

    4. 如何让视觉模型支持回归任务：骨干网络不变，将分类头 (Softmax) 移除，直接使用全连接层输出实数值并用 MSE 优化即可支持视觉坐标/数值回归。
